# AI 等距商业图表生成器

> 让 AI 为你的生意画出专业的商业图表

## 这个技能是什么？

当你需要展示一个商业概念、流程或想法时，普通老板通常会：
- 用 PowerPoint 画粗糙的方块图
- 用 Excel 表格
- 请设计师花高价做图

**有了这个技能：** 告诉 AI 你想表达什么，AI 就会生成一张精美的等距风格商业插图，像真的一样。

## 核心原理：把概念变成"真实的机器"

**AI 的思维方式：**
> 不要画方块+箭头+标签，发明一个真实存在的精密装置，让它的工作原理 = 你想表达的概念

| 你想表达的概念 | AI 画成什么 |
|---------------|------------|
| 公司各部门协作 | 一台精密仪器，齿轮互相咬合 |
| 客户购买流程 | 流水线上产品经过各个工位 |
| 数据从采集到分析 | 一台数据打印机，纸张层层处理 |
| 团队分工 | 一张工作台，每个工具各司其职 |
| 供应链流程 | 一条传送带，产品从左到右经过各个站点 |

告诉 AI：
```

```

AI 会自动：
1. 理解你的业务概念
2. 发明一个"真实的精密装置"来表达它
3. 画出精美的等距风格商业图表
4. 生成可下载的 SVG 或 HTML 文件

## 常见问题

**Q: 我完全不懂设计，能用吗？**
A: 当然可以！你只需要描述你想表达什么，AI 会帮你完成所有视觉工作。

**Q: 生成的图片可以商用吗？**
A: 可以！生成的 SVG/HTML 文件版权归你，可用于商业计划书、PPT、网站等。

**Q: 什么样的概念不能用这个技能表达？**
A: 过于抽象的概念（如哲学思想、情感表达）不适合用等距图表，建议用文字或摄影图片。

**Q: 生成的图片是什么格式？**
A: SVG（矢量格式，可以无限放大不失真）和 HTML（可直接在浏览器打开，有动态效果）。
