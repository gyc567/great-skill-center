## 二、问题清单

### 问题 1：自进化触发时机模糊（严重）

**现状**：
```
每次对话结束后（当用户说"好的"、"谢谢"或明确结束话题时），自动触发
```

**问题**：
- AI 无法可靠判断用户是否真的要结束对话
- "好的"、"谢谢"在日常对话中频繁出现，可能误触发
- 用户可能说"好的，我再想想"并不意味着对话结束

**建议修复**：
```
方案A：改为显式触发
- 用户说"记下来"、"保存"、"分析这次"时触发
- 不自动触发，由用户明确要求

方案B：会话结束时触发
- 以"会话 ID + 时间戳"为单位
- 当用户开启新会话时，分析上一个会话

方案C（推荐）：半自动 + 每日汇总
- 每次异议处理后，询问"效果如何？"
- 用户回复"成功"/"失败"时记录
- 每天生成简报时做整体分析
```

---

### 问题 2：脚本与 AI 边界不清（严重）

**现状**：
SKILL.md 写了调用 `scripts/meeting.py` 等，但 AI 实际执行时：
- Claude Code：可以执行 Python 脚本 ✅
- Claude.ai 网页版：不能执行脚本 ❌
- Claude API：需要通过 Tool Use 机制 ❌

**建议修复**：
```
1. 明确 Skill 运行环境（仅 Claude Code）
2. 提供两种执行模式：
   - 快速模式：纯 Prompt 输出（无脚本）
   - 完整模式：脚本 + 数据存储
3. 在 SKILL.md 开头标注运行环境
```

---

### 问题 3：API Key 配置缺失（中等）

**现状**：
提到 `data/config.json` 存储 API Key，但：
- 用户如何输入 API Key？
- 没有配置引导流程
- config.json 的格式未定义

**建议修复**：
```
1. 创建 config.json.example 模板
2. 在 SKILL.md 中说明首次使用需要配置
3. 提供 /setup 命令引导用户配置
```

---

### 问题 4：数据路径依赖（中等）

**现状**：
SKILL.md 写 `data/customers/`，但 Claude Code 执行时：
- 工作目录不一定是 skill 根目录
- 相对路径可能找不到文件

**建议修复**：
```
使用 __file__ 获取 skill 目录路径：
import os
SKILL_DIR = os.path.dirname(os.path.abspath(__file__))
DATA_DIR = os.path.join(SKILL_DIR, 'data')
```

---

### 问题 5：触发词冲突（中等）

**现状**：
- "查" 可能与其他 Skill 冲突
- "记录" 可能误触发文件操作
- "分析" 在多个场景中出现

**建议修复**：
```
1. 使用更具体的触发词前缀
2. 添加优先级排序
3. 冲突时要求用户确认
```

### 问题 6：冷启动数据为空（中等）

**现状**：
如果用户首次使用，没有历史数据：
- 异议数据库为空时如何处理？
- 客户列表为空时如何处理？
- 缺乏默认回复/引导

**建议修复**：
```
1. 预置完整的数据文件（objections.json 等）
2. 首次使用时展示引导
3. 提供示例数据供用户参考
```

---

### 问题 7：成功率计算逻辑未定义（中等）

**现状**：
```
如果某策略成功率变化 > 5%，更新 objections.json
```

**问题**：
- 成功率如何计算？（成功次数/总次数？）
- 5% 阈值是否合理？
- 样本量少时（如只用了 1 次）如何处理？

**建议修复**：
```python
# 成功率计算
success_rate = success_count / total_count if total_count > 0 else 0

# 更新逻辑
new_rate = (old_rate * old_count + new_success) / (old_count + 1)

# 变化阈值：样本量 >= 5 时才考虑更新
if total_count >= 5 and abs(new_rate - old_rate) > 0.05:
    update_objections_db(strategy_id, new_rate)
```

---

### 问题 8：缺乏错误处理（中等）

**现状**：
脚本假设所有操作成功，没有：
- 文件不存在时的处理
- JSON 格式错误时的处理
- API 调用失败的处理

**建议修复**：
```
每个脚本都需要：
1. try-except 包裹文件操作
2. 数据文件不存在时创建默认模板
3. 详细的错误日志
```

---

### 问题 9：数据安全和隐私（低）

**现状**：
没有提醒用户：
- 对话记录包含敏感商业信息
- 数据存储在本地
- 如何备份数据

**建议修复**：
在 README.md 中添加数据安全说明

---

### 问题 10：缺少后续跟进机制（低）

**现状**：
没有处理：
- 会议后的跟进提醒
- 客户联系频率追踪
- 漏斗进度管理

**建议修复**：
添加跟进任务功能（可选，后续迭代）

### 4.2 自进化流程（优化后）

```
1. 用户描述异议 → AI 提供策略
2. AI 询问："这个方案效果如何？【成功/失败/待定】"
3. 用户回复 → record.py 记录
4. 如果回复是成功/失败 → evolve.py 更新成功率
5. 更新后的策略会在下次优先展示
```

### 4.3 触发词（优化后）

| 触发词 | 功能 | 说明 |
|--------|------|------|
| `/会议` + 公司名 | 会议准备 | 更明确 |
| `/异议` + 描述 | 异议处理 | 避免误触发 |
| `/简报` | 每日简报 | 前缀区分 |
| `/记录` + 内容 | 记录对话 | 明确记录意图 |
| `/分析` | 自进化分析 | 主动分析 |
| `/客户` + 操作 | 客户管理 | 统一入口 |
| `/查` + 关键词 | 知识查询 | 知识库查询 |
