# 示例：洗地机

> 用 `python3 scripts/validate_fabe.py examples/示例-洗地机.md` 校验 → PASS

## 单品话术卡

- **F（特征）**：自带热风烘干滚刷
- **A（优势）**：洗完不会潮湿、不容易发霉异味
- **B（利益）**：你不用手动拆开晾晒滚刷，更省心，家里更卫生
- **E（证据）**：产品检测报告、买家实测视频

## 一句话话术

自带热风烘干滚刷，洗完不用拆下来晾，家里的滚刷不容易发霉，检测报告和买家实测视频都能当场给您看。

## 客户可能的疑问

**「这个真的假的？」**
→ 出示第三方防霉检测报告（0 级）和买家实测视频（连续使用 30 天无异味）。

**「太贵了」**
→ 一台能用三年、每天省下十分钟拆洗晾晒的时间，不用频繁换滚刷。

**「滚刷会不会坏？」**
→ 热风烘干是内置功能，出示保修卡（整机 2 年、滚刷 1 年）。
