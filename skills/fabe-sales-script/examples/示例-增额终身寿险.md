# 示例：增额终身寿险

> 用 `python3 scripts/validate_fabe.py examples/示例-增额终身寿险.md` 校验 → PASS
> ⚠️ 金融行业：收益描述与比较表述必须符合监管规定，以现行有效条款为准。

## 单品话术卡

- **F（特征）**：这是一款增额终身寿险，有固定递增
- **A（优势）**：比普通年金险更灵活，可以按需随时申请部分领取现金价值（比如孩子上学、结婚）
- **B（利益）**：提前给孩子储备教育/婚嫁资金，减轻未来经济压力
- **E（证据）**：出示保单现金价值表、合同条款、过往客户案例

## 一句话话术

这是一款固定递增的增额终身寿险，需要用钱的时候可以按需领取一部分现金价值，孩子上学的钱提前备着，压力小一些——保单现金价值表和条款都给您看。

## 客户可能的疑问

**「收益到底多少？」**
→ 出示保单现金价值表，逐年数字写在纸上；说明以现行有效条款为准。

**「和年金险比哪个好？」**
→ 出示同一张现金价值表上的领取灵活性差异：年金险按固定年份领，这款可以按需申请部分领取。

**「交了钱能退吗？」**
→ 出示合同条款中关于犹豫期和退保现金价值的条款说明。

## 客户角色变体

| 角色 | B 重心 | E 重心 |
|------|-------|-------|
| 投保人（妈妈） | 提前锁定教育/婚嫁资金，减轻收入波动压力 | 保单现金价值表 + 条款 |
| 决策人（爸爸） | 合同写明保障责任，不必口头承诺 | 合同条款 + 监管备案信息 |
| 付款人（祖辈） | 这笔钱专款专用，孩子上大学时正好能用 | 现金价值表 + 过往客户案例 |
