# 常见错误与改写对照

> 每一条都是真实销售场景里高频出现的写法。
> **左边是问题，右边是改法。**

---

## 错误 1：F/A 混淆 —— A 只是复述 F

❌
```
F：不锈钢材质，3000W 大功率电机
A：不锈钢材质，3000W 大功率电机
```
✅
```
F：不锈钢材质，3000W 大功率电机
A：顽固污渍一遍过，20 分钟能清完一间厨房
```

**规律**：A 必须出现能力类词（可以 / 能 / 支持 / 相比 / 自动 / 一次）。

---

## 错误 2：A 只有客观参数

❌
```
F：容量 4L，重量 3.2kg，功率 1200W
A：容量大、重量轻、功率强
```
✅
```
F：容量 4L，重量 3.2kg，功率 1200W
A：一次装满不用中途倒水，单手能拎起来，10 分钟蒸一锅饭
```

---

## 错误 3：B 还在说产品

❌
```
B：采用进口材料，工艺先进，通过多项认证
```
✅
```
B：你不用担心用久了磨损变形，十年后表面还是现在这样
```

**规律**：B 里出现"产品用了什么"，就该改写成"你能得到什么"。

---

## 错误 4：B 是 AI 空话

❌
```
B：提升效率，降低成本，优化体验
B：赋能业务增长，打造数字化闭环
B：全方位提升使用体验
```
✅
```
B：你每周省下两小时对账，月底直接看报表
B：客服不用再翻聊天记录找订单号了
B：老板在手机上就能看到今天进账多少
```

**规律**：**空话的特征是换成任何产品都成立。** 如果这句话套到竞争对手身上也一样，就是空话。

---

## 错误 5：E 是空话

❌
```
E：品质保证，值得信赖
E：优质服务，专业团队，值得拥有
E：销量第一，行业领先
```
✅
```
E：第三方检测报告，防霉等级 0 级
E：服务合同写明 24 小时响应，附在合同第 8 条
E：2025 年天猫同类目销量第一，这是平台后台截图
```

---

## 错误 6：E 模糊不可核验

❌
```
E：很多客户都说不错
E：用户反馈非常好
```
✅
```
E：这是[具体客户名]用了[时长]的实际情况，他遇到的问题和你一样
E：我们的差评率是 1.2%，这是后台近 30 天数据
```

---

## 错误 7：缺环节

❌
```
F：这是一款增额终身寿险，有固定递增
B：提前给孩子储备教育婚嫁资金
（缺 A 和 E）
```
✅
```
F：这是一款增额终身寿险，有固定递增
A：比普通年金险更灵活，可以按需随时申请部分领取现金价值
B：提前给孩子储备教育/婚嫁资金，减轻未来经济压力
E：保单现金价值表、合同条款、过往客户案例
```

---

## 错误 8：B 用了假对比

❌
```
B：比普通产品好多了
```
✅
```
B：同样 5000 块预算，我们多 800 块包含了[具体保障]，别家不包含
```

**规律**：对比必须**指名道姓 + 同一维度**。含糊的"比别家好"客户不信。

---

## 错误 9：把限制写成优势

❌
```
A：续航只有 4 小时
B：续航 4 小时，够用了
```
✅
```
A：单次续航 4 小时，覆盖一个完整工作日
B：一天下来不用中途插电，晚上插一次就满
```

**规律**：参数限制**不要藏**，要**框定为场景优势**。客户自己会算。

---

## 错误 10：E 用了不能出示的东西

❌
```
E：我们和 XX 品牌的内部数据对比（你拿不出来）
```
✅
```
E：这是公开的第三方评测报告，第 3 页有对比表格
```

**规律**：E 环节的标准是"**现在就能递过去**"。

---

## 自查三问

写完话术，问自己：

1. **A 是在说"能干什么"还是又在说"是什么"？**
2. **B 换成竞争对手的产品还成立吗？** 成立 = 空话。
3. **E 我现在能递给他看吗？** 不能 = 重写。
