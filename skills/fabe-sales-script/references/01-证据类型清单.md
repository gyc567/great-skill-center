# E 环节证据类型清单

> E = Evidence。作用是**打消疑虑**，所以证据必须**可出示**。
> 判断标准只有一个：**你现在能把这个东西递给客户看吗？**

---

## 一、八大证据类型

### 1. 检测报告
第三方检测机构出具的报告、SGS/CNAS 认证、质检报告、检测数据。
**适用**：家电、建材、食品、母婴、宠物用品
**话术模板**："这是[机构]出的[项目]检测报告，[关键指标]是 [数字]。"

### 2. 案例
客户案例、实测视频、买家秀、真实使用记录、同行场景复盘。
**适用**：几乎所有行业
**话术模板**："[行业]里已经有[数量]家在用，这是[客户名]用了[时长]的实际情况。"

### 3. 凭证文件
保单、合同、条款、协议、证书、发票、保修卡、说明书。
**适用**：保险、金融、租赁、订阅制服务
**话术模板**："这份是合同条款，[第几条]写明[保障内容]，白纸黑字。"

### 4. 数据表格
现金价值表、价格表、费率表、参数表、横向对照表。
**适用**：保险、金融、硬件规格
**话术模板**："这是[年份]的[表名]，您看第[行]，[数字]是写在纸上的。"

### 5. 演示
现场演示、免费试用、demo、沙箱环境。
**适用**：SaaS、硬件、企业服务
**话术模板**："要不现在开一个试试？您自己填一条数据看看结果。"

### 6. 评价
用户评价、评分、权威认证、获奖、行业榜单。
**适用**：消费品牌、教育、餐饮
**话术模板**："我们是[奖项名]，[年份]拿的，证书在这儿。"

### 7. 对比
横向对比表、实测数据、同价位竞品对照。
**适用**：参数党决策的产品
**话术模板**："同样是[价位段]，左边是我们，右边是[竞品]，差别就在这一栏。"

### 8. 公开背书
媒体报道、上榜、官方认可、行业协会推荐。
**适用**：企业级采购、需要降低决策风险的场景
**话术模板**："[媒体名][日期]报道过，[链接或截图]。"

## 二、证据强度排序

```
最强 ▓▓▓▓▓▓▓▓  第三方检测报告 / 监管备案 / 合同条款
     ▓▓▓▓▓▓▓   真实客户案例 + 可核验数字
     ▓▓▓▓▓▓    现场演示 / 试用
     ▓▓▓▓▓     真实用户评价（带图带名）
     ▓▓▓▓      媒体报道 / 榜单
     ▓▓▓       "很多客户都说好"          ← 不算证据
     ▓         "品质保证"                 ← 不算证据
```

---

## 三、常见行业证据速查

| 行业 | 最强证据 | 常见误区 |
|------|---------|---------|
| 保险 | 保单现金价值表、条款、监管备案 | 用"收益率"替代具体数字 |
| 家电 | 检测报告、参数对比表、实测视频 | 只说"品质好" |
| SaaS | 演示、标杆客户案例、第三方评测 | 只讲功能不讲客户结果 |
| 课程 | 学员作品、结业数据、导师资质 | 只说"名师授课" |
| 咨询/服务 | 合同 SLA、过往项目成果 | 只说"专业团队" |
| 金融 | 费率表、监管备案、历史数据 | 承诺收益 |
| 教育 | 学员反馈、成绩数据、教研资质 | 只讲师资名气 |
| 餐饮 | 食品安全证、后厨直播、真实探店 | 只讲"新鲜" |

---

## 四、不能用的"证据"

| ❌ 说法 | 为什么不行 | ✅ 替换为 |
|--------|-----------|----------|
| 品质保证 | 拿不出东西 | 出示保修卡 + 售后条款 |
| 值得信赖 | 主观形容词 | 出示客户案例和评价截图 |
| 销量第一 | 无来源 | 出示榜单截图或销售数据 |
| 行业领先 | 范围不明 | 出示具体排名和机构 |
| 很多客户说好 | 不可核验 | 出示 3 个具体客户案例 |
| 专家推荐 | 查不到 | 出示专家名字、机构、链接 |
| 绿色环保 | 空泛 | 出示检测报告的具体指标 |

---

## 五、多证据组合

单个 E 显得单薄时，按这个顺序组合：

```
1 个强证据（报告/条款）
  + 1 个场景证据（案例/演示）
    + 1 个对比证据（对照表）
```

**话术模板**：
> "这是[检测报告]，指标是[X]；[客户名]用了[时长]，是[具体场景]；同一价位我们和[竞品]的差别在[对照表这一栏]。"
