# 行业适配表 —— B 和 E 的重心差异

> FABE 的 F 和 A 在各行业差异不大，**真正要按行业定制的是 B（客户收益）和 E（证据类型）**。

---

## 一、保险 / 金融

| 环节 | 要点 |
|------|------|
| **F** | 保障责任、递增比例、领取规则、缴费方式 —— **必须是条款里的原文** |
| **A** | 相比普通年金险更灵活，可按需部分领取（孩子上学、结婚时） |
| **B** | 提前锁定教育/婚嫁资金，减轻未来收入波动的压力；这笔钱用的时候才拿，不用一直放着 |
| **E** | **保单现金价值表**（纸面上写死数字）、合同条款、监管备案信息 |

⚠️ **红线**：不得承诺收益、不得与其它产品做无依据比较、必须提示"以现行有效条款为准"。

---

## 二、家电 / 实物产品

| 环节 | 要点 |
|------|------|
| **F** | 材质、功率、容量、续航、配件 |
| **A** | 能力描述："一遍过""不用拆洗""连续工作 2 小时" |
| **B** | 省下什么动作、家里什么变化——"不用每周拆洗滚刷""晚上洗完第二天早上能用" |
| **E** | 第三方检测报告、参数对比表、买家实测视频 |

⚠️ **红线**：性能数据必须与检测口径一致；"静音""除螨率"这类要标测试条件。

---

## 三、SaaS / 软件

| 环节 | 要点 |
|------|------|
| **F** | 功能清单、集成数、部署方式、并发限制 |
| **A** | "一条命令就能出报告""不用自己写脚本""对接现有系统不用迁移" |
| **B** | 节省的工时、减少的人力、不用额外招人、出错率下降 |
| **E** | 现场演示、标杆客户案例与数据、第三方评测、安全认证 |

⚠️ **红线**：不要把"功能多"当成 benefit，客户买的是"少做什么"。

---

## 四、课程 / 教育

| 环节 | 要点 |
|------|------|
| **F** | 课时数、导师背景、课程模块、作业批改次数 |
| **A** | "不用从零学起""每个模块都有模板""作业有人逐条改" |
| **B** | 能独立做出什么作品、能拿到什么证书、省下多少自学时间 |
| **E** | 学员作品集、结业数据、导师资质证书、在读学员反馈 |

⚠️ **红线**：就业承诺、薪资数字、学员成果必须可核验。

---

## 五、咨询 / 专业服务

| 环节 | 要点 |
|------|------|
| **F** | 团队规模、方法论、服务范围、交付物、周期 |
| **A** | "先诊断再出方案""驻场 3 天交付原型""不成功不收费" |
| **B** | 少走弯路、少花冤枉钱、内部能直接落地、出问题有人兜底 |
| **E** | 过往项目成果、合同 SLA、同行客户推荐信、现场演示 |

---

## 六、餐饮 / 消费

| 环节 | 要点 |
|------|------|
| **F** | 产地、配方、工艺、门店数量、出品速度 |
| **A** | "现做不用预制""每天两趟冷链""出餐 8 分钟" |
| **B** | 家人吃得放心、临时聚会不用等、口味稳定 |
| **E** | 食品安全证、后厨直播、真实探店视频、回头客数据 |

---

## 七、同一产品按客户角色改写

| 角色 | B 重心 | E 重心 | 话术语气 |
|------|-------|-------|---------|
| **决策者**（老板/高管） | 成本、风险、ROI、团队效率 | 标杆案例、对比数据、合同保障 | 结论先行，数据支撑 |
| **使用者**（执行层） | 省事、好用、少学一遍 | 演示、试用、界面截图 | 场景化，具体到动作 |
| **付款人**（财务/采购） | 值不值、够不够、怎么结算 | 报价单、条款、资质 | 条款清楚，无歧义 |

**同一个产品，三种客户，B 和 E 完全不同 —— 这是 FABE 用得对不对的分水岭。**
