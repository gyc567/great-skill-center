# FABE 销售法则 · fabe-sales-script

> **把产品客观特点，翻译成客户能感知到的价值。**
> F(Feature) → A(Advantage) → B(Benefit) → E(Evidence)，四级闭环。
> 内置机械校验器，**当场拦住"F/A 混淆"和"空话套话"**。

## 🎯 它解决什么问题

写产品介绍时，几乎每个人都会犯这两个错：

| 错误 | 症状 |
|------|------|
| **A 复述 F** | 「产品有热风烘干」→「产品有热风烘干」—— 还是没说能干什么 |
| **B 继续说产品** | 「采用进口材料，工艺先进」—— 客户还是不知道对他有什么用 |
| **E 是空话** | 「品质保证，值得信赖」—— 拿不出任何东西，客户的疑虑没被消除 |

**肉眼很难发现这些问题** —— 因为每一句单看都通顺。

所以这个 Skill 的重点不是"讲一遍 FABE 理论"，而是**配一个校验器，把能机械判定的问题直接判掉**。

## ✨ 五个特点

### 1️⃣ 五项机械校验，不靠感觉

```
python3 scripts/validate_fabe.py 话术.md
```

| 校验项 | 判定规则 |
|--------|---------|
| **四级齐全** | F/A/B/E 都存在，缺一个就 FAIL |
| **A 不复述 F** | 与 F 词重叠 ≥50% 且 ≥2 词 → FAIL；或 A 只有客观参数无能力描述 → FAIL |
| **B 落到客户** | 无客户视角表述 → FAIL；以「提升效率/降低成本/优化体验」等 AI 空话开头 → FAIL |
| **E 可出示** | 未命中任何证据类型 → FAIL；含「品质保证/值得信赖/销量第一」等空话 → FAIL |
| **无空话套话** | 汇总全部层级的问题数 |

每条问题都附**具体修法**，不是只说"不合格"。

### 2️⃣ 八大证据类型词典

检测报告 / 测试报告 / 案例 / 凭证文件 / 数据表格 / 演示 / 评价 / 对比 / 公开背书
—— 写 E 时必须落到其中一类，且**真的能递过去**。

### 3️⃣ 证据强度排序

```
最强 ▓▓▓▓▓▓▓▓  第三方检测报告 / 监管备案 / 合同条款
     ▓▓▓▓▓▓▓   真实客户案例 + 可核验数字
     ▓▓▓▓▓    现场演示 / 试用
     ▓▓▓▓▓     真实用户评价（带图带名）
     ▓▓▓▓      媒体报道 / 榜单
     ▓▓▓       "很多客户都说好"          ← 不算证据
     ▓         "品质保证"                 ← 不算证据
```

### 4️⃣ 七行业适配表

保险 / 家电 / SaaS / 课程 / 咨询 / 餐饮 / 金融 ——
每个行业的 **B 重心**和**E 重心**都不同，还带各自的红线提醒。

### 5️⃣ 客户角色变体

同一个产品，对**决策者 / 使用者 / 付款人**三种角色的 B 和 E 完全不同。
这是 FABE 用得对不对的分水岭。

## 📖 快速上手

```bash
# 1) 写好话术（Markdown）
cat > 话术.md <<'EOF'
- F：自带热风烘干滚刷
- A：洗完不会潮湿、不容易发霉异味
- B：你不用手动拆开晾晒滚刷，更省心，家里更卫生
- E：产品检测报告、买家实测视频
EOF

# 2) 校验
python3 scripts/validate_fabe.py 话术.md
# → PASS 全部机械校验通过

# 3) JSON 输出（批量处理用）
python3 scripts/validate_fabe.py 话术.md --json

# 4) 跑自检测试
python3 tests/test_validate_fabe.py
```

## ⚠️ 实测发现的坑

| 坑 | 说明 |
|----|------|
| **"测试报告"一开始不在证据词典里** | 自己写的 SaaS 示例被自己的校验器判 FAIL —— 补进「测试报告」类型后通过。**这说明词典需要按行业持续扩充** |
| **空话词典不能收得太宽** | 第一版把「数据」加进数据表格，结果空话可能蒙混过关 —— 收紧成「实测数据」 |
| **B 的判定要看受益人，不一定要有"你"字** | 「提前给孩子储备教育婚嫁资金，减轻未来经济压力」没有第二人称，但受益人明确 —— 扩充了受益词表 |
| **校验器会有误判** | 产品名本身含「材质」等词可能触发误报。**大多数时候它是对的**，但被误报时说明该调整措辞 |

## 📚 FABE 速查卡

| | 问自己 | 好的样子 | 坏的例子 |
|---|-------|---------|---------|
| **F** | 产品是什么？ | 不锈钢材质，3000W 电机 | —— |
| **A** | 这特点能干什么？ | 顽固污渍一遍过 | 不锈钢材质，3000W 电机 ❌ |
| **B** | 对我有什么好处？ | 你不用每周拆洗滚刷 | 工艺先进，采用进口材料 ❌ |
| **E** | 凭什么让你相信？ | 第三方防霉检测报告 | 品质保证，值得信赖 ❌ |

**一句话自检**：
> **B 换成竞争对手的产品还成立吗？成立 = 空话。**
> **E 现在能递给他看吗？不能 = 重写。**
