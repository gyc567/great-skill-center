# LaunchSkill · 产品全景启动技能

> 帮你在动手之前，就完成商业验证

## 模块 0：验证（Validation）—— 最重要的一步

> **原则：先卖再做。在写第一行代码之前，先验证有人愿意买。**

### 核心问题

在开始任何开发工作之前，你必须回答以下问题：

| 问题 | 为什么重要 |
|------|-----------|
| 谁会买你的产品？ | 没有具体买家，任何功能都是空转 |
| 他们现在用什么替代方案？ | 了解竞争和差异化空间 |
| 你打算收多少钱？ | 价格决定了定位和目标人群 |
| 你如何找到前 10 个付费用户？ | 不知道渠道 = 无法启动 |

### 输入格式

请告诉 AI 你的：

```
产品：一句话描述你的产品（做什么的）
目标市场：[国内 / 海外 / 双线]
当前阶段：[仅有想法 / 已有 MVP / 已有付费用户]
```

### 输出 1：买家画像卡片

```
╔═══════════════════════════════════════╗
║           买家画像 #1                 ║
╠═══════════════════════════════════════╣
║  姓名：________________（给个代号）   ║
║  角色：________________              ║
║  痛点：________________              ║
║  当前替代方案：________________       ║
║  付费能力：________________          ║
║  最可能在哪个渠道出现：__________     ║
╚═══════════════════════════════════════╝
```

### 输出 2：定价假设分析

| 定价策略 | 适合产品类型 | 优缺点 |
|---------|------------|--------|
| 免费 + 付费增值 | 工具类产品 | 获客容易，转化难 |
| 订阅制（月/年）| SaaS 产品 | 稳定现金流，客户质量高 |
| 一次性买断 | 插件/模板 | 简单，但续费少 |
| 按量付费 | API / 消耗类产品 | 弹性大，预测难 |

**建议：** 先用"替代方案价格 × 0.5~0.8" 作为定价起点。

### 输出 3：验证清单

```
□ 写出 3 句话的产品介绍，发给 5 个潜在用户，收集反馈
□ 在 Reddit / 即刻 / V2EX 发帖子，看有没有人主动询问
□ 创建一个落地页（Notion/Typeform），收集"感兴趣"邮箱
□ 设定一个预售目标（如 10 人付费），看能不能完成
□ 找到至少 3 个竞品，分析他们的弱点（你的机会）
```

**验证通过的标准：** 有陌生人主动表示愿意付钱，而不是"这个不错"。

## 模块 1：Find —— 用户在哪？

> 找到潜在用户聚集的地方，才能有效触达。

### 竞品分析

请提供竞品名称或你所在领域的关键词，AI 会帮你：

1. **列出竞争对手**
2. **提取用户评论中的痛点**（Reddit / Twitter / Product Hunt）
3. **找出高频抱怨** → 这是你的切入点

### 社区发现矩阵

| 平台 | 适合类型 | 特点 |
|------|---------|------|
| Product Hunt | 工具 / SaaS / 独立开发者 | 曝光强，但竞争激烈 |
| Indie Hackers | SaaS / 商业化产品 | 社区氛围好，创始人聚集 |
| Reddit | 垂直领域工具 | 需要长期运营，精准用户 |
| 即刻 / 知识星球 | 国内开发者 | 社群氛围强，付费意愿高 |
| V2EX | 技术型产品 | 用户质量高，但流量有限 |
| 小红书 | 泛工具 / toC | 流量大，需内容种草 |
| Twitter/X | 全球用户 | 传播快，但用户注意力碎片 |

### 输出：你的前 3 个社区

根据你的产品类型，AI 会推荐最值得投入的 3 个社区，并给出：
- **入驻建议**（如何不被人当成广告）
- **内容选题方向**（什么内容能引起共鸣）
- **KOL 推荐**（谁是这个领域的活跃声音）

## 模块 2：Reach —— 如何触达用户？

### 冷启动渠道清单

| 渠道 | 成本 | 时间投入 | 适合产品 | 优先级 |
|------|------|---------|---------|--------|
| Reddit 评论区 | 低 | 中 | 工具类产品 | ⭐⭐⭐ |
| Indie Hackers 分享 | 低 | 高 | 有故事的 SaaS | ⭐⭐⭐ |
| Twitter/X thread | 低 | 高 | 有洞察的内容 | ⭐⭐⭐ |
| 即刻发帖 | 低 | 低 | 国内产品 | ⭐⭐⭐ |
| Product Hunt 发布 | 中 | 高 | 正式发布 | ⭐⭐ |
| 知乎/小红书 | 中 | 高 | toC 产品 | ⭐⭐ |
| 付费广告 | 高 | 低 | 有明确 ROI 的产品 | ⭐ |

### Lead Magnet 策略

什么是 Lead Magnet？用免费的东西吸引潜在用户留下联系方式。

| 类型 | 例子 | 适合产品 |
|------|------|---------|
| 免费工具 | 小计算器 / 检查器 | 工具类 |
| 模板包 | Notion 模板 / Prompt 集合 | 效率类产品 |
| 内容合集 | PDF 指南 / 视频教程 | 知识类产品 |
| 早期访问 | MVP 优先体验权 | 任何产品 |

### 输出：你的前 30 天内容日历

```
第 1 周：发布"为什么这个领域有机会"分析帖
第 2 周：分享你的制作过程（behind the scenes）
第 3 周：发布产品预告，收集邮箱订阅
第 4 周：公开发布，开始收集付费用户
```

## 模块 3：Convert —— 如何让用户付费？

### 落地页必备元素

一个能卖货的落地页必须包含：

```
[ ] 标题：一句话说清楚你是谁 + 解决什么问题
[ ] 副标题：详细说明谁适合用
[ ] 功能截图/演示：让用户看到产品长什么样
[ ] 社会证明：用户评价 / 使用数据 / 媒体曝光
[ ] 定价方案：清晰的价格，不要藏着掖着
[ ] CTA 按钮：明确告诉用户下一步做什么
[ ] 风险逆转：退款政策 / 免费试用 / 保障条款
```

### 转化话术模板

**描述痛点：**
> "你是不是也遇到过……（目标用户的具体困境）"

**描述方案：**
> "（产品名称）帮你……（用动词描述具体效果）"

**行动号召：**
> "现在就开始 / 立即体验 / 马上订阅"

### 试用设计

| 试用类型 | 适用场景 | 转化率 |
|---------|---------|--------|
| 永远免费版 | 工具类产品 | 高注册，低付费 |
| 7天试用 | SaaS 产品 | 中等 |
| 30天退款保证 | 高单价产品 | 高信任 |
| Freemium（免费增值）| 产品功能分层明显 | 需要精细运营 |

## 模块 4：Get Paid —— 如何收款？

### 国内收款方案

| 方案 | 适合场景 | 手续费 | 开通难度 |
|------|---------|--------|---------|
| 支付宝收款码 | 私域 / 社群 | 低 | 极低 |
| 微信支付商户 | 公众号/小程序 | 中 | 低 |
| Alipay / PayPal | 出海产品 | 中 | 低 |
| Lecang / Paddle | SaaS 订阅 | 中高 | 中 |
| Stripe | 全球收款 | 低 | 中 |

### 海外收款方案

| 方案 | 适合场景 | 优点 | 缺点 |
|------|---------|------|------|
| Stripe | 全球 SaaS | 生态完善 | 需要海外主体 |
| Paddle | 工具类产品 | 税务自动化 | 费率较高 |
| Lemon Squeezy | 独立开发者 | 极简上手 | 功能有限 |
| Gumroad | 数字产品 | 最简单 | 定制化弱 |

### 主体建议

| 产品类型 | 建议主体 | 原因 |
|---------|---------|------|
| 纯国内产品 | 个人 / 中国公司 | 合规简单 |
| 出海 SaaS | 美国 Delaware C-Corp / 香港公司 | 银行账户易开 |
| 数字产品 / 模板 | 美国 LLC | 成本低，报税简单 |

**⚠️ 重要提醒：** 合规建议仅供参考，实际操作请咨询专业会计师或律师。

## 模块 6：Retain —— 如何让用户留下？

### 用户留存框架

**新用户 onboarding 3 步：**

```
Step 1：完成关键动作（让用户感受到第一个价值）
  → 给用户一个"5分钟就能完成的第一个任务"
  
Step 2：建立使用习惯
  → 发送第 3/7/30 天的引导邮件
  → 在产品内设置"使用里程碑"提醒
  
Step 3：创造社区归属感
  → 邀请加入专属社群
  → 让用户互相帮助（社区 > 客服）
```

### 流失预警信号

| 信号 | 应对措施 |
|------|---------|
| 注册后 7 天未使用 | 发送 re-engagement 邮件 |
| 试用快到期但不活跃 | 提供限时福利 |
| 付费后 30 天未回访 | 主动询问使用困难 |
| 连续 2 个月付费下降 | 主动沟通，了解原因 |

### 转介绍机制

| 机制 | 适合产品 | 效果 |
|------|---------|------|
| 推荐奖励（双方得积分）| SaaS 产品 | ⭐⭐⭐⭐ |
| 分享解锁功能 | 工具类产品 | ⭐⭐⭐ |
| 用户评价墙 | toC 产品 | ⭐⭐⭐ |
| 联盟分成（20%~30%）| 高单价产品 | ⭐⭐⭐⭐⭐ |

## 模块 7：合规 —— 你忽略但重要的部分

### 合规检查清单

| 检查项 | 说明 | 优先级 |
|--------|------|--------|
| 隐私政策 | 说明你如何收集、存储、使用用户数据 | 必须 |
| 服务条款 | 明确你和用户的权责 | 必须 |
| 退款政策 | 明确什么情况可以退款 | 必须 |
| 增值税（海外）| 欧盟 VAT / 美国销售税 | 重要 |
| 数据跨境传输 | 中国→海外用户的数据合规 | 重要 |
| 未成年人保护 | 如有未满 18 岁用户 | 重要 |

### 各平台规则提醒

| 平台 | 需要注意的规则 |
|------|--------------|
| 支付宝 / 微信 | 禁止虚拟产品刮卡 / 抽奖类内容 |
| Product Hunt | 禁止 self-promotion 超过 10% |
| Reddit | 禁止直接发广告，需先贡献社区 |
| App Store / Google Play | 需要隐私政策 + 年龄分级 |

## 检查清单：发布前必做

```
□ 买家画像已验证（至少 3 个真实反馈）
□ 定价已确认（通过预售或调研验证）
□ 至少 1 个获客渠道已测试（有人回复你的帖子）
□ 支付流程已测试（自己走一遍完整购买流程）
□ 隐私政策和服务条款已发布
□ 至少 3 个真实用户在等待发布
□ 产品有明确的上线日期
□ 准备了发布后的用户沟通渠道（社群 / 邮箱）
□ 知道从哪里看到数据（注册率 / 转化率 / 付费率）
□ 预留了时间处理发布后的用户问题
```

## 局限性说明

**这个技能不能替你做：**
- 替你找到愿意付费的真实用户（但能告诉你去哪里找）
- 替你写代码 / 做设计（但能告诉你该做什么）
- 保证你的产品成功（但能帮你降低试错成本）

**这个技能能替你做：**
- 提供经过验证的商业框架和清单
- 帮你梳理思路、发现盲点
- 告诉你已经成功的人是怎么做的
- 提醒你容易忽略的重要步骤
