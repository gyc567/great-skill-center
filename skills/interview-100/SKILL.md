# 面试百问精选

> 100道高频面试题，附标准答法要点

## 自我介绍（必问）

**Q1: 请做一下自我介绍**
要点：3分钟以内 / 学历+经历+技能+动机
公式：[我是谁] + [核心技能] + [代表项目] + [为什么选这家公司]

**Q2: 你的最大缺点是什么？**
要点：诚实但可控 / 正在改进
模板：承认缺点 → 说明意识到 → 正在做什么改变

**Q3: 为什么离职？**
要点：正向表达 / 绝不吐槽前公司
模板：成长诉求 + 发展需求 + 主动离职

## 项目经历（高频）

**Q4: 请介绍你最成功的一个项目**
要点：STAR法则 / 量化结果 / 个人贡献
模板：Situation(背景) → Task(任务) → Action(行动) → Result(结果)

**Q5: 项目中遇到最大困难是什么？**
要点：真实困难 + 解决方案 + 学习到
避坑：别说"团队不给力"

**Q6: 你在项目中具体负责什么？**
要点：具体职责 / 技术决策 / 数据结果
公式：我的角色 → 核心工作 → 最终指标

**Q7: 项目如何推进的？**
要点：流程清晰 / 协作能力 / 主动性强
模板：定计划 → 分任务 → 盯进度 → 复盘改进

## 技术问题（IT/产品岗）

**Q8: 你最熟悉的技术栈是什么？**
要点：说深入 / 能讲原理 / 有实战
公式：语言/框架 → 做了什么项目 → 深入到哪个层面

**Q9: 如何解决线上故障？**
要点：排查思路 + 解决速度 + 复盘
模板：发现问题 → 定位原因 → 快速止血 → 复盘改进

**Q10: 你未来的技术规划是什么？**
要点：方向明确 / 与公司发展匹配
模板：短期(1年) → 中期(3年) → 最终目标

## 行为面（高频通用）

**Q11: 你如何处理同事间的分歧？**
要点：沟通能力 + 换位思考
STAR示例：描述分歧场景 → 我的处理方式 → 结果

**Q12: 压力最大的时候怎么办？**
要点：真实经历 + 健康应对方式
模板：场景 → 压力源 → 我的应对（找方法/找人帮忙）

**Q13: 你如何学习新技能？**
要点：自学能力 + 学习方法论
公式：目标 → 资源 → 实践 → 输出

**Q14: 5年后你想成为什么样的人？**
要点：野心与现实的平衡
模板：专业深度 + 能力拓展 + 行业影响

## 薪资谈判

**Q15: 期望薪资是多少？**
要点：说区间 / 有理有据 / 留余地
公式：市场价位 + 个人能力 + 合理上限
