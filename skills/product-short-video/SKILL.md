# 产品短视频生产线 (Product Short Video)

## 用途

把「一张产品图 + 一段产品介绍」自动转成一条可直接投放的短视频，核心机制是 **预设套路模板 + 产品信息替换 + 分镜化生产**。无需第三方付费系统、无需手动打开剪辑软件。

## 何时使用

- 用户给产品图/产品描述，要求「生成一条宣传视频 / 带货视频 / 广告片 / 种草视频」
- 用户要做短剧带货（剧情中植入产品，而不是直接拍产品）
- 用户要做产品视频的 A/B 测试、批量产出不同版本
- 用户已有素材或脚本，要求按模板快速改版（换剧情类型、换人物、换风格、改字幕/价格）

## 六条铁律（违反即失去本技能的价值）

1. **先给方向，再生产（最重要）**：拿到需求后**绝不立刻开工**。先输出 **6 个创意方向** 让用户挑选，或允许用户直接给自定义剧情。
2. **一致性锚定**：先产出「主体设定卡」（产品外观锚定描述 + 主角形象锚定描述），后续**所有**分镜 prompt 复用同一段锚定文本，保证跨镜头一致。
3. **分镜先行**：先出分镜表（`时间 | 画面 | 运镜 | 字幕 | 音效`），再逐镜生成静态图，再由图生成视频。禁止跳过脚本直接"一段到底"。
4. **分层生产**：精确信息（文案/价格/Logo/数据）属于**确定性层**，由后期确定性叠加；画面属于**生成层**，其 prompt 必须**禁止出现文字/Logo**（否则渲染为乱码）。
5. **对话迭代，只重跑受影响环节**：用户不满意时，换方向只重跑 Phase 1–4；改字幕/价格只重跑 Phase 5；禁止全流程重来。
6. **全部交付**：关键帧图片、分镜视频片段、最终成片、分镜脚本文档**全部**交付，不得把中间素材当作"内部产物"隐藏。

## 全流程（7 个阶段）

### Phase 0 · 输入采集与能力预检

先确认两样输入，缺失则主动询问（不要臆造）：

- **产品图**（可选）：无图则走文生图；有图则首帧优先用图生图/图生视频以保产品还原度。
- **产品介绍**：卖点、目标人群、价格定位、品牌调性。
- **投放参数**（缺失时给默认值并告知）：平台与画幅（抖音/小红书/视频号默认 **9:16 竖屏**）、时长（默认 **15 秒**）、是否要配音/BGM/字幕。

预检：本技能只做"产品短视频"，若用户要的是视频分析/翻译/纯剪辑，应转相应能力，不要硬套。

### Phase 1 · 生成 6 个创意方向（CRITICAL）

围绕产品重新设计 **6 个互不相同的方向**，每个方向给出：`编号 | 类型 | 一句话概念 | 3–5 镜分镜大纲 | 建议时长/画幅`。让用户「挑一个」或「自定剧情」。

从下面的方向库中选 6 个最契合产品的（默认剧情类 3 个 + 非剧情类 3 个）：

**剧情植入类**（产品藏在故事里，用户看剧情、记住产品）
- 霸道总裁追妻：高端感、身份反差，适合礼赠/高档快消
- 逆袭打脸：前后对比、爽感，适合功能型产品
- 悬疑反转：钩子强、完播高，适合新奇产品
- 家庭伦理反击：情绪共鸣、中老年受众，适合日用/健康品

**非剧情类**
- 奢品调性：极致暗调 + 微距 + 大留白，把日常品做成"消费不起"（见 `references/prompt-library.md` 实战范例）
- 硬广种草：痛点 → 产品 → 卖点 → 促单，节奏快、转化直给
- 对比测评：横向对比/前后对比，理性说服
- 情绪共鸣：金句 + 场景 + 产品，适合情感/生活方式品类

用户选定后，进入生产。

### Phase 2 · 主体一致性设定卡

输出一张「设定卡」，锁定后续所有 prompt 的可复用描述片段：

```
产品锚定：<材质、颜色、造型、光效，一段固定英文/中文描述>
主角锚定（剧情类需要）：<年龄感、发型、服装、气质，一段固定描述>
风格锚定：<影调、打光、镜头质感、画幅>
调色/字体规范：<主色、字幕字体与颜色，如 香槟金 #D4AF37 + 衬线细体>
负面约束：<no text, no logo, no watermark, no extra fingers ...>
```

### Phase 3 · 分镜脚本 + 分镜图

1. 先写**分镜表**（Markdown 表格），逐镜填：`镜号 | 时长 | 画面描述 | 运镜 | 字幕文案 | 音效/旁白`。
2. 按分镜表**逐镜生成关键帧**：每镜 prompt = `设定卡锚定片段 + 该镜画面描述`。风格锚定词必须逐字复用。
3. 生成后目检：一致性、光效、有无文字残留；不合格只重生成该镜。

细节模板见 `references/prompt-library.md`。

### Phase 4 · 分镜视频

- **有分镜图** → 图生视频（推荐 `yt-video-2.0`；人物出镜用 `yt-video-humanactor`；特效模板用 `yt-video-fx`）
- **无分镜图** → 文生视频（`hy-video-1.5`）
- 每镜单独生成，运镜词写进 prompt（dolly-in 推近 / dolly-out 拉远 / pan 横移 / 静态微动）。
- 遇 `JobNumExceed` / 队列繁忙等**临时性错误**：退避 1–3 分钟后重试，不要改需求。
- 遇**安全拦截**：调整措辞去掉敏感点后重试；连续失败 2 次即终止并告知用户。

### Phase 5 · 后期合成

按 `references/edit-recipes.md` 执行：

1. 拼接 + 转场（叠化 xfade 0.5s）
2. 统一调色（降饱和/加对比/暖金/暗角）
3. 精确时长（`tpad` 补帧或 xfade 计算，凑整到目标秒数）
4. 确定性层叠加：字幕/价格/Logo（优先 `scripts/assemble_video.py`）
5. 音频：按需加静音轨/BGM/配音
6. QC：`ffprobe` 校验 + 抽帧目检（字幕、转场、边界）

### Phase 6 · 对话迭代

接收自然语言修改并**最小化重跑**：

| 用户说 | 只重跑 |
|---|---|
| 「换个类型，要悬疑风」 | Phase 1→4（复用设定卡） |
| 「人物换成年轻女性」 | Phase 2→4 |
| 「字幕字体换一下 / 价格改一下」 | Phase 5 |
| 「节奏再快一点」 | Phase 5（改单镜时长与转场） |
| 「分镜图风格再写实一点」 | Phase 3→5 |

## 模型与工具映射

| 环节 | 首选 | 备选 |
|---|---|---|
| 文生图/分镜图 | 高质量文生图模型、ImageGen | 快速文生图模型（批量/草稿） |
| 图生图/编辑 | ImageEdit | 高质量文生图模型 img2img |
| 图生视频 | `yt-video-2.0` | `hy-video-1.5` |
| 文生视频 | `hy-video-1.5` | — |
| 人物视频 | `yt-video-humanactor` | `yt-video-2.0` |
| 特效视频 | `yt-video-fx` | — |
| 剪辑/调色/字幕 | `scripts/assemble_video.py`（ffmpeg） | 手动 filtergraph |

**成本优先**：优先选用免费/低成本的可用模型，整条链路通常只需 1 个图像模型 + 1 个视频模型即可完成，不要无谓调用多个模型。

## 质量与合规红线

- 禁止生成涉及未成年人的任何内容；禁止违规内容。
- 保留平台"AI 生成"标识（合规要求），除非用户明确要求且场景允许去除。
- 统一输出目录（如 `outputs/`），并在最终回复中列出**全部**产物路径。
- 视频生成本身耗时数分钟，务必提前告知用户预期等待时间。

## 反模式（不要做）

- ❌ 拿到需求直接生成一条视频 → 应先给 6 个方向
- ❌ 每个分镜自由发挥、风格漂移 → 应复用设定卡锚定
- ❌ 让生成模型渲染文字/价格/Logo → 应走确定性层叠加
- ❌ 只交付成片、丢掉关键帧与分镜片段 → 应全部交付
- ❌ 用户改一个字幕就整条重跑 → 应最小化重跑
