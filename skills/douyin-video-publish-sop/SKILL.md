# 抖音短视频制作与发布 SOP（卡片大字版）

一条"风景图 + 大字文案卡片 + 激励 BGM"型抖音竖版短视频的完整制作与发布流程，经两期真实成片验证（第 1 集《做IP答疑两条赚钱路线》29.1s、第 2 集《老板也会失业》28.9s，均已成功发布）。产出物：1080×1920 竖版 mp4 + 发布后的审核确认。

## 适用与选题路由

先用一句话判定本集类型，再选模板：

| 类型 | 特征 | 数据表现（实测参考） | 适用模板 |
|---|---|---|---|
| **情绪故事型** | 以"某类人"的真实困境开场，场景化细节，结尾给盼头 | 单条天花板最高（同题最高 18.9 万赞） | 六卡故事结构（见下） |
| **方法论型** | 信息密度高，可"抄作业"，清单/步骤感 | 收入稳定，起号期保底 | 直接落点式（钩子→3-5 个方法→CTA） |

- 情绪故事型适合做**连载人设**（如"失业老板自救"系列），每集延续同一主角处境与同一句 CTA。
- 制作前若属商业粉/创业赛道，先跑"每日低粉爆款监测"日报，选取已被验证的同题选题。

## 六卡情绪故事文案结构（核心模板）

每张卡 = 1 个情绪节拍，节奏固定为：**低谷开场 → 场景细节 → 转折（止痛≠治病）→ 资产觉醒 → 方法 → CTA**。

| 卡序 | 节拍 | 文案要点 | 对应背景意象 |
|---|---|---|---|
| c1 | 低谷开场 | 身份+变故+隐瞒（"40岁 公司没了 三个月没敢告诉家里人"） | 冷调、模糊、压抑 |
| c2 | 场景细节 | 具体到"一天怎么过"（"咖啡厅坐一天 假装开会 怕催债电话"） | 冷峻、空旷 |
| c3 | 转折 | 否掉常见出路，给认知差（"跑滴滴送外卖=止痛不是治病"） | 开阔、海岸 |
| c4 | 资产觉醒 | 重新定义资产（"不是职位 是判断力/人脉/操盘经验"） | 壮美、公路/雪山 |
| c5 | 方法 | 给路径（"把经验做成个人IP→信任→下一个生意"） | 亮色、光轨/爆发感 |
| c6 | CTA | 互动钩子+进群（"评论区扣『1』 我拉你进群"） | 暖色、盼头 |

**文案写作规则**：
- 每卡主标题 ≤12 字（黄字），副标 ≤25 字/行（白字），卡 1 必须 3 秒内戳中人群身份。
- 多用具体数字与场景（"三个月""手机一响"），少用抽象形容词。
- CTA 卡必须给"零门槛动作"（扣 1、进群），禁止只写"关注我"。

## 选图原则（免费图库）

- 素材源：免费风景图库（如 free-stock 目录，109 张）；**禁止用视觉中国等付费图/带水印图**。
- 每集 6 张背景，**全部换新**，不与上集重复。
- 情绪递进 = 色调递进：c1 冷调压抑 → 中间过渡 → c6 暖色盼头（见上表"对应背景意象"）。
- 画幅：优先选原生 1080×1920；非 9:16 原图用 `ImageOps.fit` 居中裁剪（实测 1080×1728 → fit 后 1080×1920 无损主体）。
- 快速筛选：先按亮度/色温自动粗筛，再逐张目视确认；排除含人脸/文字/商标/海报的图。

## 卡片生成（scripts/gen_cards.py）

配置 `cards.json`（6 条记录），运行 `python3 gen_cards.py cards.json`，输出 `cards/c1.png … c6.png`。

已验证参数（1080×1920 画布）：

| 元素 | 值 |
|---|---|
| 主标题 | 黄 RGB(255,200,40)，Bold，88-96px，黑描边 4px，上下黑条遮罩 110 alpha |
| 副标题 | 白 RGB(255,255,255)，Bold，52px，黑描边 3px |
| 遮罩 | 顶部 220px / 底部 230px，黑 110 alpha（压暗背景保文字可读） |
| 画幅 | 一律 1080×1920（fit 居中裁剪非 9:16 原图） |

> 用户偏好"字要大"：主标 96px 优于 84px，后续可继续按需求上调。

## 结尾灰词埋词（scripts/gen_ending.py）

复用 [douyin-search-word-ending](../douyin-search-word-ending/SKILL.md) 已验证参数：结尾定格 **0.1 秒**、亮灰 RGB(205,205,205)、**alpha≈115（45%）**、Bold 24px、4 行共 40 词左右、行距 42px、y 起 675（避开主文字区）。

- 词库按四类分层：核心词（3-5）/ 症状痛点词（10）/ 方法方案词（10）/ 场景人群词（10）。
- 灰词强度标准：转码后"肉眼隐约可见 + OCR 可读"（像素差 ≥10），过淡会被 H.264 抹平。

## 合成（scripts/compose.sh）

```bash
bash compose.sh "cards/c1.png cards/c2.png cards/c3.png cards/c4.png cards/c5.png cards/c6.png" cards/ending.png assets/bgm.mp3 boss_epN.mp4
```

- 每卡 **4.8s**（6 卡 = 28.8s）+ 尾帧 **0.1s** → 总时长 ≈ 28.9s。
- 输出：H.264 / yuv420p / **30fps / 1080×1920** / aac 128k / `-movflags +faststart`。
- BGM：凯乐石式激励音乐（96s 素材），`atrim=0:28.9` + 结尾 `afade=t=out:st=28.3:d=0.6`。

## 质量验证（发布前必做）

1. **OCR 逐卡**：对 6 张卡片原文 OCR，确认主副标题无错字、无溢出（背景干扰大时直接 Read 目视）。
2. **抽帧**：抽卡 1（开场）、中间卡、尾帧，确认画面/文字/灰词层均在。
3. **规格**：`ffprobe` 确认时长 ≈ 28.9s、1080×1920、30fps、含 aac 音轨。

## 发布（抖音创作者中心，详见 references/douyin-publish-flow.md）

核心顺序：**登录 → 上传视频 → 标题（≤30字，情绪钩子）→ 话题（3-4 个，带 # 逐个输入+回车）→ 正文（补场景化描述+CTA）→ 封面（竖版选/传首帧卡，横版让平台自动生成）→ 自主声明（内容由AI生成）→ 发布 → 短信验证（用户接管）→ 审核确认**。

发布配套（提升流量）：
- 标题前置核心词；话题 3-4 个（如 #老板 #创业 #失业 #个人IP）。
- 正文 ≤1000 字，含完整故事线 + 评论区扣 1 CTA。
- 封面用卡 1（最强钩子帧）；发文助手提示横封面缺失时点"设置横封面"或让平台基于竖版自动生成。

## 踩坑记录（实测）

- **话题输入**：必须输入 `#词` + 回车逐个确认，直接输入不带 # 的文本不会变成话题标签。
- **登录/验证**：创作者中心登录与发布前短信验证必须 `interaction.request_action(type="browserControl")` 交接用户，绝不代收验证码。
- **封面**：竖版先上传 1080×1920 首帧卡；横版缺失不影响发布，可让平台"基于竖封面生成横封面"。
- **发布确认**：点"发布"后可能停在原页（等待短信弹窗），验证通过后自动跳转内容管理页；新作品状态"审核中"为正常，刷新后可见。
- **灰词**：埋词强度过低会白埋（见 douyin-search-word-ending 实测表）。

## 输出交付

1. 确认选题类型与系列名（连载则延续人设与 CTA）。
2. 产出 `cards.json` + 6 卡 + 尾帧 + 成片 mp4。
3. 报告验证结果（OCR/抽帧/ffprobe 规格）。
4. 完成发布，确认进入审核，给出作品标题与账号。
