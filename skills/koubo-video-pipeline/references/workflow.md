# 六阶段详细操作手册

本手册是 SKILL.md 工作流的展开版，含每阶段逐步命令、参数选择与验收标准。所有命令中的路径按实际环境替换。

## 阶段 1：选题调研（可选）

**触发**：用户未指定选题，或要求验证赛道/对标账号。

**检索组合**（WebSearch，每轮换角度，至少 3 轮）：
1. `视频号 低粉账号 涨粉10万 案例`
2. `视频号 爆款视频 转发量 10万 素人`
3. `新榜 视频号 涨粉 排行榜 黑马`
4. `视频号 0粉起号 爆款 涨粉 2025`
5. `视频号 <目标赛道> 爆款 账号`（如三农/情感/银发/短剧）

**口径**：低粉 = 起号粉丝 < 1 万（含 0 粉/个位数粉）；爆款 = 单条涨粉 > 10 万 或 单条转发/点赞 > 10 万。

**核实要点**：
- 平台归属：区分视频号原生爆款与抖音/快手爆火后同步（案例表单独分区并标注平台）
- 数据标注来源；自媒体来源标「数据待核验」
- 大盘校准：腾讯财报（月活/时长）、新榜（百万粉账号数）、新视（年度双 10 万+ 爆款条数）用于判断赛道冷热

**产出物**：选题结论（赛道 + 钩子 + 结构公式）。典型结论：
- 爆款五要素选题：婆媳/育儿冲突、正能量金句、萌娃家庭、实用教程、普通人叙事
- 结构公式：黄金 3 秒钩子 + 冲突-反转-金句；单条只讲一个道理
- 数字结果体标题：`一个月用 AI，直接省了 30 万`

## 阶段 2：照片 → 人物口播视频

### 2.1 素材确认

```bash
ls -la "<照片路径>" && file "<照片路径>"
```

用 ViewImage 分析：人物位置（居中/偏左/偏右）、动作表情、背景明暗、**有无水印**（AI 生成的照片常带角标，记录位置以便后续裁剪去除）。

### 2.2 调用 VideoGen

输入照片 + 文字描述。描述模板：

```
<口播稿全文，停顿点用标点体现>
画面要求：以照片人物为主体进行口播，保持人物外貌、眼镜、服装等形象特征与照片一致；
人物面向镜头自然说话，口型与台词匹配，表情自信、有镜头交流感；
背景保持简洁干净；商务知识口播风，真实自然，避免夸张表演。
时长约 10 秒；竖屏 9:16；1080P。
```

注意：
- 口播稿全文必须逐字写入，转写核验时以此为基准
- 该工具为「图片+文字描述」驱动，无音频驱动唇形能力；配音由模型生成，需转写核验
- 模型直出常为横屏（如 10:9），需竖屏化

### 2.3 竖屏化

```bash
ffmpeg -y -v error -i "<横屏原片>.mp4" \
  -vf "crop='min(iw,ih*9/16)':'min(ih,iw*16/9)',scale=1080:1920,setsar=1,format=yuv420p" \
  -c:v libx264 -preset medium -crf 18 -c:a copy "<竖屏输出>.mp4"
```

若需保留偏右构图（如人物偏左），用手动裁剪：`crop=iw*9/16:ih:<x偏移>:0`。裁剪后必须抽帧确认人物头/肩/手势完整。

### 2.4 核验三件套

```bash
# ① 参数
ffprobe -v error -show_entries format=duration,size:stream=codec_type,codec_name,width,height \
  -of default=noprint_wrappers=1 "<视频>.mp4"

# ② 首/中/尾三帧拼图
ffmpeg -y -v error -i "<视频>.mp4" -vf "select='eq(n\,0)+eq(n\,120)+eq(n\,240)',scale=270:480,tile=3x1" \
  -frames:v 1 /tmp/check.png

# ③ 音频提取 + 转写
ffmpeg -y -v error -i "<视频>.mp4" -vn -ac 1 -ar 16000 -f wav /tmp/audio.wav
# 然后用 AudioTranscribe 工具转写 /tmp/audio.wav，与口播稿逐字比对
```

**硬指标**：转写文本与口播稿一致。不一致时：重生成，或在阶段 6 前补 TTS 配音替换音轨。

## 阶段 3：片尾福利卡片

```bash
scripts/add_endcard.sh "<口播正片>.mp4" "<福利图>.jpg" "<输出>.mp4" [卡片时长=3.5] [转场=0.5]
```

自验清单：
- [ ] ffprobe：1080×1920、帧率与源一致、时长 = 源 + 卡片 − 转场、含 AAC
- [ ] 抽卡片段一帧 ViewImage：福利图完整清晰、居中、无变形、背景融合自然
- [ ] 尾段 volumedetect ≈ -91 dB（静音）
- [ ] 转场帧无黑帧/跳变

卡片设计原则：**静态**（禁动画）、福利图内容完整不被裁切、背景色从图片四角采样。

## 阶段 4：文案物料

按 `references/publish-copy.md` 模板输出三平台标题/正文/hashtag。硬规则：
- 标题用数字结果体，数字与封面、口播一致
- 视频号正文带 emoji 序号列表 + 明确 CTA（红心关注/先截图）
- hashtag 8–10 个，平台词 + 人群词 + 场景词组合

## 阶段 5：封面设计

两种风格二选一（命令见 SKILL.md），生成后 ViewImage 核验清单：
- [ ] 所有文字完整无缺字（逐行核对传入参数）
- [ ] 人物面部无遮挡（风格 A 文字在左、人物在右）
- [ ] 水印无残留（风格 A 靠 crop-x 裁掉）
- [ ] 层级分明：数字焦点 > 主标题 > 辅助行 > 条幅
- [ ] 1080×1920，无元素超出画布

封面同时承担两个职能：视频片头 + 视频号上传封面（封面即钩子）。

## 阶段 6：合成与核验

```bash
scripts/add_opening.sh "<封面>.png" "<带片尾版>.mp4" "<完整版>.mp4" [片头停留=2.5] [转场=0.5]
```

终检四件套：
1. ffprobe：1080×1920 / 24fps / 时长 = 片头 + 正片 − 转场 / 含 AAC
2. 抽 4 关键帧 ViewImage：片头 / 转场中（人物与卡片或封面融合，无黑帧）/ 口播中 / 片尾卡片
3. 分时段 volumedetect：片头段静音、人声段正常、尾段静音
4.（可选）成片音轨 AudioTranscribe 终确认

交付：完整版 mp4 + 封面 PNG + 发布文案（阶段 4 产物）。

## 交付物清单模板

```

口播视频_<主题>_原始横屏备份.mp4        # 模型直出备份（可选保留）
口播视频_<主题>_带<福利名>.mp4          # 带片尾卡片（阶段 3）
封面_<标题数字>.png                    # 封面/片头（阶段 5）
口播视频_<主题>_完整版.mp4              # 最终成片（阶段 6）
发布文案.md                            # 三平台文案（阶段 4）
```
