# 封面设计规范

封面是视频号主页第一触点，同时承担「视频片头」与「上传封面」双职能。所有封面 1080×1920 竖屏 PNG。

## 风格 A：探店爆款封面风（有参考图时默认）

### 范式拆解（来自真实探店爆款封面）

| 元素 | 规范 |
|---|---|
| 真人照片全铺 | 照片铺满竖屏，真实场景建立信任 |
| 人物靠右、文字居左 | 人物不挡文字，文字不挡脸 |
| 超大字标题 | 占画面 1/3 以上，三层堆叠 |
| 黄字黑边 | 明黄色填充 + 深色描边，高对比，信息流一眼可辨 |
| 关键词放大 | 数字（金额）做到全屏最大字号，金色渐变 |
| 深色圆角条幅 | 底部承载次要信息，白字 + 关键词黄色 |
| 左侧压暗 | 黑色渐变层（x=0 处 150 强度 → x=860 处 0），保证黄字任何背景可读 |
| 暖色高饱和 | 黄色激发金钱/兴奋感 |

### 参数表（scripts/design_cover.py）

| 参数 | 默认 | 说明 |
|---|---|---|
| `--crop-x` | 120 | 裁剪起点，控制人物水平位置，越小越靠右；调大同时用于裁掉右下角水印 |
| `--text-x` | 64 | 文字左边界 |
| `--line-white` | 一个月用 AI | 第一行白字 82px |
| `--line-gold` | 直接省了 | 第二行金色渐变 138px，描边 14 |
| `--line-hero` | 30 万 | 第三行超大 205px 金色，描边 16（视觉焦点） |
| `--bar1/--bar2` | — | 底部条幅 y=1470/1600，`[ ]` 内文字为黄色关键词 |
| `--bg-dim` | 0.94 | 照片亮度系数，压暗提升文字对比 |

### 三层标题字号节奏

```
第一行（白）      82px   引子
第二行（金渐变）  138px  动作/结果
第三行（超大金）  205px  数字焦点 ← 全屏最大
条幅              46px   辅助信息
```

## 风格 B：海报风（无参考图时）

### 参数表（scripts/design_title_card.py）

| 参数 | 默认 | 说明 |
|---|---|---|
| `--badge` | 2026 · 老板必看 | 顶部金色描边 pill |
| `--line1` | 一个月用 AI | 白字 94px |
| `--hero` | 直接省了（带尾空格） | 粗宋金色渐变 + 外发光，150px 自适应 |
| `--chip` | 30 万 | 金色圆角高亮块 + 深色字（与底部 CTA 胶囊呼应） |
| `--line3` | 就靠换了这 6 个岗位 | 灰白 60px |
| `--cta` | ★ 先截图保存 · 红心关注 ★ | 底部金色渐变 pill |
| `--foot` | 第 7 个工具 · 下条视频补 | 金色小字 34px |

### 配色

| 用途 | 色值 |
|---|---|
| 背景渐变 | 深海军蓝 #091123 → #132240 |
| 金色主色 | #FFC452 |
| 金色亮（渐变顶） | #FFEBAF |
| 金色深（渐变底） | #FFAC28 |
| 文字白 | #F6F8FC |
| 文字灰白 | #CBD2E0 |

### 装饰元素

- 四角细金框（inset 56, arm 96, width 5, 透明度 150）
- 中部双圆环（r=400 透明度 60 / r=470 透明度 28）
- 金色径向光晕（标题后方 peak 80 blur 90）
- 金色装饰分隔条（540±300, 高 12, 圆角 6）

## 字体规范（macOS 环境）

| 用途 | 字体 | 索引 |
|---|---|---|
| 粗宋大标题（海报风 hero） | /System/Library/Fonts/Supplemental/Songti.ttc | 0 = Songti SC Black |
| 黑体标题/条幅 | /System/Library/Fonts/Hiragino Sans GB.ttc | 2 = W6（粗） |
| 黑体小字 | 同上 | 0 = W3（细） |

脚本内已内置 Linux Noto CJK 回退路径；换环境时先跑一次渲染并 ViewImage 核验缺字。

## 核验清单（生成后必查）

- [ ] 所有文字完整无缺字（与传入参数逐行核对）
- [ ] 风格 A：人物面部无遮挡、人物靠右、水印无残留
- [ ] 风格 B：高亮块内深色字清晰可读、与渐变字对齐
- [ ] 层级分明：数字焦点 > 主标题 > 辅助行 > 条幅/CTA
- [ ] 无元素超出画布或被裁切
- [ ] 封面标题与视频标题、口播稿三处数字一致

## 水印处理

用户上传的 AI 生成照片常带「AI 生成」角标（左上或右下）。处理优先级：
1. 风格 A：通过 `--crop-x` 右侧裁剪，让人物靠右同步去掉右下水印
2. 裁剪会伤构图时：先用 buddy-image-processing 技能去水印，再进封面脚本
3. 交付前在封面帧与视频帧中双重确认无残留
