# 三平台发布文案模板库

## 一、标题：数字结果体（核心格式）

用户验证过的高完播标题格式，**具体金额 + 时间限定**，越具体越有说服力。

### 基础句式

| 句式 | 示例 |
|---|---|
| 一个月用 AI，直接省了 XX 万 | 一个月用 AI，直接省了 30 万 |
| 一个月用 AI，赚了 XX 万 | 一个月用 AI，赚了 50 万 |
| 当老板的注意：一个月用 AI 省了 XX 万 | 当老板的注意：一个月用 AI 省了 50 万 |

### 数字选择规则

| 受众 | 金额区间 | 说明 |
|---|---|---|
| 小微企业主/个体老板 | 10–20 万 | 数字太大像吹牛，具体才可信 |
| 中型企业主 | 30–50 万 | 与「6 个岗位」量级匹配 |

**硬规则：标题、封面、口播三处的数字必须一致。**

1. **封面 = 片尾福利图同款**，压上封面字「一个月用AI，直接省了30万 / 6个岗位，全换 / 先截图保存」——封面即福利，与「先截图」话术闭环，拉高完播与保存率。

3. **系列化**：「第 7 个下条补」是天然的追更钩子，成片系列需保持标题格式、封面版式、条幅位置三统一。
