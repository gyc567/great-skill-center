# Koubo Video Pipeline — 口播短视频全流程流水线

## Overview

把「一张人物照片 + 一段口播稿」变成一条可直接发布的完整短视频：人物开口说话的口播正片、片尾可截图的福利卡片、设计师级封面、配套的三平台发布文案。全程本地工具链（VideoGen + ffmpeg + PIL），不依赖外部服务。

## 工作流总览（六阶段）

| 阶段 | 输入 | 动作 | 产出 |
|---|---|---|---|
| 1 选题调研（可选） | 赛道/主题 | 全网检索低粉爆款账号，验证选题 | 选题结论 |
| 2 口播生成 | 人物照片 + 口播稿 | VideoGen 生成 → 竖屏化 → 配音核验 | 口播正片 mp4 |
| 3 片尾卡片 | 福利图（工具清单等） | ffmpeg 片尾卡片 + xfade 转场 | 带片尾版 mp4 |
| 4 文案物料 | 成片内容 | 数字结果体标题 + 三平台文案 | 发布文案 |
| 5 封面设计 | 人物照片 + 标题 | PIL 封面脚本（两种风格） | 封面 PNG |
| 6 合成核验 | 各段素材 | 片头接入 + 参数/画面/音频核验 | 完整版 mp4 |

每阶段详细操作步骤、命令参数与验收标准见 `references/workflow.md`。

## 阶段 1：选题调研（可选）

当用户没有明确选题、或需要验证赛道方向时执行：

- 用 WebSearch 做多轮组合检索（如「视频号 低粉账号 涨粉10万 案例」「视频号 爆款 转发10万 素人」「新榜 视频号 涨粉 排行榜」），至少 3 轮不同角度。
- 口径固定：低粉 = 起号时粉丝 < 1 万（含 0 粉起号）；爆款 = 单条视频带动涨粉 > 10 万，或单条转发/点赞 > 10 万。
- 必须核实平台归属，区分「视频号原生爆款」与「抖音爆火后同步」；跨平台案例单独标注，仅作参照。
- 所有数据标注来源；来源可信度存疑的标注「数据待核验」；禁止编造账号名、数字或来源。
- 产出：赛道结论 + 爆款五要素选题（婆媳/育儿冲突、正能量金句、萌娃家庭、实用教程、普通人叙事）+ 结构公式（黄金 3 秒钩子 + 冲突-反转-金句），喂给阶段 2。

## 阶段 2：照片 → 人物口播视频

1. **确认素材**：`ls` + `file` 确认照片存在与格式；用 ViewImage 分析构图（人物位置、动作表情、背景明暗、有无水印）。
2. **调用 VideoGen**：上传照片作为输入图，文字描述中完整写入口播稿全文（停顿点用标点体现，如「老板最该省的不是人｜是重复劳动」），并附画面要求——保持人物外貌/服装与照片一致、面向镜头自然说话、口型与台词匹配、背景简洁、商务知识口播风。参数：时长约 10 秒、竖屏 9:16、1080P。
3. **竖屏化**：模型常直出横屏（如 10:9），用 ffmpeg 居中裁剪 + 缩放到 1080×1920，抽帧确认人物头肩完整无裁切（命令见 `references/ffmpeg-recipes.md`）。
4. **核验三件套（缺一不可）**：
   - ffprobe 核验分辨率/时长/编码；
   - 抽首/中/尾三帧 ViewImage：人物完整、开场动作保留、中帧口型张合、无黑帧；
   - 提取音轨转写（AudioTranscribe 工具），与口播稿**逐字比对**——配音与文案一致是硬指标，不一致必须重生成或后期补 TTS。

## 阶段 3：片尾福利卡片（截图型内容专用）

当口播稿含「工具组合在最后 / 先截图保存」类话术时执行：

```bash
scripts/add_endcard.sh <原视频.mp4> <福利图.jpg> <输出.mp4>
```

- 福利图等比缩放居中放入 1080×1920 深色画布（背景色自动从图片四角采样），卡片静态展示 3.5 秒，结尾 0.5 秒 xfade 交叉溶解，人声淡出后补静音至全片结束。
- **卡片必须静态**——禁止任何缩放/平移动画，保证观众截图清晰。
- 自验：ffprobe + 抽卡片段一帧 ViewImage（内容完整、清晰、居中、背景融合）+ 尾段 volumedetect（应 ≈ -91dB 数字静音）。

## 阶段 4：发布文案物料

标题采用「数字结果体」格式（高完播验证格式）：

- 主格式：`一个月用 AI，直接省了 30 万` / `一个月用 AI，赚了 50 万`
- 数字按受众选：小微企业主用 10–20 万，中型企业用 30–50 万；**标题、封面、口播三处数字必须一致**。
- 完整标题变体、视频号/抖音/小红书三平台正文与 hashtag 模板见 `references/publish-copy.md`。

## 阶段 5：封面设计（两种风格）

封面是视频号主页第一触点，用 PIL 脚本生成 1080×1920 PNG，同时作为视频片头和上传封面（封面即钩子，与「先截图」话术闭环）。

**风格 A — 探店爆款封面风（有参考图时默认）**：

```bash
python3 scripts/design_cover.py --photo 人物照片.jpg --out 封面.png \
  --line-white "一个月用 AI" --line-gold "直接省了" --line-hero "30 万" \
  --bar1 "6 个岗位，AI 全包了" --bar2 "第 7 个下条补 · 先截图保存"
```

真人照全铺 → 人物靠右（右侧裁剪同步去除 AI 水印）→ 左侧黑色渐变压暗 → 黄字黑边三层大标题（白字/金渐变/超大数字）→ 底部深色圆角色条幅。

**风格 B — 海报风（无参考图时）**：

```bash
python3 scripts/design_title_card.py --out 片头.png \
  --badge "2026 · 老板必看" --line1 "一个月用 AI" --hero "直接省了 " --chip "30 万" \
  --line3 "就靠换了这 6 个岗位" --cta "★ 先截图保存 · 红心关注 ★" --foot "第 7 个工具 · 下条视频补"
```

深色渐变底 + 金色径向光晕 + 粗宋大标题 + 数字金色高亮块 + 徽章 pill + 底部 CTA 胶囊。

设计规范、配色、字体、版式参数见 `references/cover-design.md`。生成后必须 ViewImage 核验：文字无缺字、不遮挡人物面部、水印已去除、层级分明。

## 阶段 6：合成与核验

1. **片头接入**：

```bash
scripts/add_opening.sh <封面.png> <口播视频.mp4> <完整版输出.mp4>
```

黑场淡入 0.35s → 封面静音停留 2.5s → 0.5s xfade 交叉溶解进正片，原音频 adelay 对齐时间轴。最终总时长 = 片头 + 正片 − 转场重叠。

2. **终检四件套**：
   - ffprobe：1080×1920 / 24fps / 时长符合公式 / 含 AAC 音轨；
   - 抽 4 关键帧（片头 / 转场中 / 口播中 / 片尾卡片）ViewImage：无黑帧、无跳变、内容完整；
   - 分时段 volumedetect：片头段 ≈ -91dB 静音，正片人声段正常，尾段静音；
   - 可选：对成片音轨做 AudioTranscribe，终确认文案无误。
3. **交付**：完整版 mp4 + 封面 PNG，并提示用户封面可直接用作视频号主页封面。

## 硬性规则

- 禁止编造任何账号名、数据、来源；不确定的内容标注「数据待核验」或略写。
- 原文件不动：每阶段输出新文件，保留全部中间版本供用户回溯。
- 照片带 AI 生成水印时，优先通过构图裁剪去除，并在核验中确认无残留。
- 停顿与语速：把停顿点写进生成描述，但不承诺精确到毫秒；高要求场景提示用户后期用剪辑工具校准。
- 转场统一用 xfade fade；福利卡片必须静态；xfade offset = 前段时长 − 转场时长。
- 数据口径：本流水线中「爆款」指单条涨粉/转发/点赞 > 10 万，案例间不同维度指标分别标注，不横向加总。
