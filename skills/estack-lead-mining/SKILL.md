# Estack-lead-mining：抖音评论客户线索挖掘

## 这是什么

帮你在抖音大V评论区里，批量捞出**真正有购买意向的人**，并且给你**他本人的抖音主页链接**——点进去就能联系。不是给你一堆积压的评论，而是给你一份可直接跟进的客户名单。

**一句话流程**：赛道关键词 → 找爆款视频 → 抓公开评论（带 sec_uid）→ AI 分意向 → 出带抖音号的 Excel。

## 三段能力（对应三个文件）

```
Estack-lead-mining/
├── SKILL.md                    # 本说明
├── crawler.py                  # ①抓公开评论（含评论者抖音主页链接）
├── main.py                     # ②AI 分级 + ③调度总入口
├── scripts/
│   └── build_leads_xlsx.py     # ④导出带抖音主页链接的 Excel
├── requirements.txt
└── examples/                   # 示例输入输出
```

### ① crawler.py —— 抓公开评论（带抖音号）

输入一个抖音视频链接，输出该视频评论区**平台未登录也能看到的公开评论**，每条包含：

| 字段 | 说明 |
|---|---|
| nickname | 评论者昵称 |
| sec_uid | 抖音用户唯一标识 |
| user_url | **抖音主页链接**（`douyin.com/user/{sec_uid}`，点进去直接找到这个人） |
| text | 评论文本 |
| create_time | 评论时间 |
| digg_count | 点赞数 |
| ip_location | 评论者IP属地（部分返回） |

**技术说明（诚实版）**：走的是 `iesdouyin.com/web/api/v2/comment/list/` 公开评论接口。它返回的正是浏览器不登录也能看到的那批评论（点赞最高/最热），`sec_uid` 是用户主页的公开标识，等价于你在评论区看到用户名后点进主页。**不是**破解签名、不是绕过登录、不抓私密数据。

```bash
python3 crawler.py --video "https://www.douyin.com/video/7676028838417059099" --out /tmp/comments.json
```

### ② main.py —— AI 分级

读入评论 JSON，逐条分 P0/P1/P2，输出带画像和回复话术的结构化结果。

**意向分级标准（通用）**

- **P0 高意向**（立刻跟进）：主动问价/问钱、报预算、求带、求加入、说"想报名/想学/想合作"、带自己具体处境（"我投了300万""我有家店"）
- **P1 中意向**（值得回）：问细节、问流程、零基础能不能学、靠谱吗、在观望、对比同行
- **P2 低意向/同行**（不回）：灌水、表情、666、同行普法/广告、纯分享自己经历无诉求

```bash
python3 main.py --comments /tmp/comments.json --product "我的产品" --out /tmp/leads.json
```

### ③ build_leads_xlsx.py —— 导出 Excel

把分级结果写成带**抖音主页链接超链接**、按 P0/P1/P2 分 sheet 的 Excel。

```bash
python3 scripts/build_leads_xlsx.py --input /tmp/leads.json --output "./线索表.xlsx"
```

## 用法示例

```bash
# 一键：给赛道关键词，直接出 Excel
python3 main.py --keyword "股权纠纷律师" --product "股权律师咨询" --max_videos 5 --out ./线索表.xlsx
```

## 硬边界（不能越）

- ✅ 可以做：读**平台公开可见**的评论、提取公开的 sec_uid 主页链接、AI 分类、写公开评论回复话术、导出 Excel。
- ❌ 不能做：
  - 不做自动私信、不批量私信轰炸、不群发。跟进行为必须是**人工一对一**。
  - 不破解登录态、不逆向签名、不抓**非公开**数据（手机号、私聊记录、付费内容）。
  - 不抓取用户个人隐私用于骚扰。sec_uid 只用于人工在平台内正常联系。
  - 用户要求"自动私信/自动加微信/群控多账号"时，明确拒绝并说明这是万流汇那套，封号+违法。

## 合规提醒（每次输出自带）

> 本工具只读平台公开评论并做语义分析。所有跟进必须人工、一对一、在抖音平台内正常进行。
> 批量私信、骚扰、倒卖线索违反《个人信息保护法》与平台规范，可能导致封号与法律责任。
> 律师等特许执业行业：公开答疑不承诺胜诉、不私下收费。

- 本地商家：餐饮获客、装修、留学中介、宠物美容
