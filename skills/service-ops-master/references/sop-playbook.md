## 阶段 A｜获客与触达

### A1 全域导流

| 渠道 | 案例做法 | 你要做的 |
|------|---------|---------|
| 公众号 | 公司号 + 个人号 | 建 1 个公司号 + 1 个个人号 |
| 视频号 | 只有个人号（预估粉丝 14 万） | 个人号为主，公司号可不设 |
| 抖音 | 公司号 + 个人号都有粉丝群 | **粉丝群不重点运营**，只同步内容引导加微信 |
| 抖音 | 重点运营平台 | 日更 |
| 微信 | 公众号→关注提醒加微信；视频号→简介加微信 | 落点唯一：个人微信 |

**关键技巧**：
> **"不同账号引导关注的微信不同，也便于统计。"**

→ 每个渠道导向**不同的微信号**，才能知道哪个渠道有效。

**导流路径表（自己填）**：

| 渠道 | 引导话术 | 导向微信号 | 引导素材 |
|------|---------|-----------|---------|
| 公众号 | | | 关注自动回复 |
| 视频号 | | | 简介 + 置顶评论 |
| 抖音 | | | 评论区置顶 + 私信 |
| 小红书 | | | 简介 + 私信 |
| 线下 | | | 工牌/名片/台卡 |

### A2 事件营销

**公式**：`真实素材 → 稀缺感 → 大额让利 → 圈层裂变 → 微信落点 → IP 记忆点`

#### 案例 A：互怼事件（1 天 1 亿）

| 环节 | 原始数据 |
|------|---------|
| 背景 | 抖音大V"世界抬杠冠军大蓝"在豪车毒老纪家喜提一台劳斯莱斯后，大吼"被老纪割韭菜了！" |
| 动作 | 双方互发一条视频 |
| 涨粉 | 1 天 +2 万 |
| 后台私信 | 8360 条 |
| 导入私域 | 6300 人（**导入率 75.3%**） |
| 48 小时 | 带来 6300 个精准订单 |
| 明确意向订单 | 9.7 亿 |
| 当天真实成交 | 1 亿 |

**可复制动作清单**：
1. 选一个**同量级**、有冲突潜力的账号
2. 设计一个**有梗的冲突点**（"被割韭菜了"这种）
3. 双方各发一条视频，**必须互发**
4. 评论区置顶引导私信
5. 私信里给"特殊待遇"制造稀缺
6. 24-48 小时内出成交战报

#### 案例 B：找老纪事件（80 万 → 5000 万）

| 环节 | 原始数据 |
|------|---------|
| 素材来源 | 润米咨询创始人刘润真实朋友圈："万圈，最近对豪车毒的老纪很感兴趣。谁正好认识，是否方便介绍一下?感谢。" |
| 操盘 | 私域肖厂长借势营销，**假装在朋友圈找老纪** |
| 老纪动作 | 砸 80 万红包（另一版本记为 380 万）撬动互联网各大社群私域裂变 |
| 朋友圈曝光 | 几十万 |
| 找上门的 VC | 100+ |
| 新增私域客户 | 30000+ |
| 成交 | 2 台库里南 + 3 台宾利 + 2 台法拉利 = **5000 万** |

**老纪原话**：
> **"『找老纪』是我策划的第三个营销事件，之前策划的『一条视频 9 亿意向订单』、
> 『尊贵的库里南车主』等话题，都在特定圈层里实现了刷屏。"**

**可复制动作清单**：
1. 找到/制造一条**真实的第三方发问**（可以是客户、可以是合作方）
2. 你方账号**假装在找**，把需求公开化
3. **大额红包**（相对客单价要有冲击力）撬动社群
4. 红包设计成"转发即得"或"介绍即得"
5. 高潮时**本人现身**，让事件沉淀为 IP 记忆点

#### 案例 C：付费社群与线下

| 渠道 | 原始动作 |
|------|---------|
| 付费私董会 | **交 200 万**加入现象级网红海参哥的私董会 |
| 行业大会 | 2021-06-17 首届中国实体店电商大会（山东济宁），主题演讲《新私域、新服务》 |
| 研习社 | 2021-07-27 第一期通明研习社·思维分享会，主题《用服务性思维解锁私域流量运营和服务》 |
| 企业家游学 | 2021-09-15 天下杭商精董班 1-6 期学员走进"豪车毒" |
| 媒体专访 | 电商志专访、《疫情下的破局者》 |
| 企业内训 | 蚂蚁集团、七匹狼、水星家纺等 |
| 计划 | **"我还安排了 100 多场线下分享，希望借此接触蚂蚁集团、七匹狼、水星家纺等企业中的意向客户。"** |

**主题命名规律**：《新私域、新服务》——**含"新"字制造新鲜感**。

### A3 账号矩阵（IP 分身）

| 项 | 案例数据 |
|----|---------|
| 微信主号 + 副号 | 合计 **80+ 个**（2020 年） |
| 个人微信号（2021） | **180+ 个** |
| 沉淀意向客户 | 20 万 |
| 购买 100 万+ 豪车的高端家庭客户 | 8000+ 组 |
| 其中上市公司企业家/高管 | 140+ 家 |
| 承接方式 | 9 名助理管理 |

**分工机制**：
- 每个微信号有**独立的沟通人格**（有的严谨、有的活泼、有的专业）
- 但**服务标准统一**（标准化流程 + 个性化定制）
- 客户感知是"多位专家在为我服务"

**低姿态原则（老纪原话）**：
> **"创始人能放低姿态，和用户走得很近，这种低姿态反而能呈现出他的高度，
> 但一定要把控好尺度。"**

**具体动作**：抖音评论区两天内发 2000+ 条"尊贵的库里南车主"——
在别人的热点下面刷自己的记忆点。

## 阶段 B｜沉淀与建档

### B1 沉淀路径

```
公众号关注 → 自动回复 → 加微信（号A）
视频号简介 → 加微信（号B）
抖音私信   → 加微信（号C）
朋友圈/直播 → 加微信（号D）
                        ↓
              统一进入「个人号池」→ 助理分配 → 标签化
```

### B2 客户建档（自己建，案例未公开细节，按可执行版本设计）

**必备字段**：

| 字段 | 用途 |
|------|------|
| 客户 ID | 主键 |
| 来源渠道 | 归因（对应 A1 的不同微信号） |
| 等级 | SVIP / VIP / 普通（对应权益级别） |
| 家庭成员 | 接送孩子、体检三人、看全家福需要 |
| 车辆/主品类 | 复购与配件推荐 |
| 忌口/偏好 | 私人家宴、礼品选择 |
| 关键日期 | 生日、纪念日、孩子生日（服务触发点） |
| 服务记录 | 做过哪些服务、评分、素材链接 |
| 关系人 | 保安/阿姨/前台/司机（见 D3） |
| 生日/纪念日提醒 | 下一次服务的由头 |
| 转介绍记录 | 介绍过谁、成交没 |

### B3 画像与分级

**依据可触达性 + 消费力 + 关系亲密度**三维度：

| 级别 | 判定 | 权益 |
|------|------|------|
| SVIP | 高客单 + 高频互动 + 有转介绍记录 | 26 项全清单 |
| VIP | 中客单 或 高互动 | 核心项（10-15 项） |
| 普通 | 低频 | 引流款 + 基础服务 |

**分层原则**：**服务成本随等级线性上升，但成本占比 ≤ 毛利 20%。**

## 阶段 C｜极致交付（核心 SOP）

### C1 受理与诊断

| 步骤 | 动作 | 输出 |
|------|------|------|
| 1 | 记录原始需求（文字/语音） | 需求原话 |
| 2 | 询问**场景**（送给谁、什么场合、有什么人） | 场景卡 |
| 3 | 询问**禁忌**（过敏、不喜欢、不能出现的东西） | 禁忌清单 |
| 4 | 判断是否命中"极致项目" | 是/否 |
| 5 | 匹配权益项（可能 1 项，可能组合多项） | 服务方案 |
| 6 | 客户确认（微信文字确认） | 确认记录 |

**关键**：第 2、3 步最容易被跳过，但**场景和禁忌**决定了能不能做出"惊艳"。

---

### C2 方案定制

> **"标准化流程 + 高端客户个性化定制"**

**标准层（对所有客户相同）**：
- 流程节点固定
- 行为规范固定（三条铁律）
- 素材规格固定
- 质检标准固定

**定制层（每个客户不同）**：
- 现场细节（插花样式、菜品、音乐、布置）
- 物品偏好
- 禁忌规避
- 现场人员/家属的特殊要求

---

### C3 过程播报（最容易被忽略但价值极高的一步）

> **"我们会在情感上做一些有温度的东西。比如我们会每晚把保洁的进度、完成效果发给用户，
> 可以让用户更加信任我们。"**

**执行规则**：

| 时点 | 动作 | 素材 | 目的 |
|------|------|------|------|
| 开始前 | 告知预计到达/开始时间 | — | 降低不确定 |
| 过程中 | 关键节点拍照 | 现场图 | 参与感 |
| 每天/每阶段结束 | **进度 + 完成效果汇报** | 对比图 | 信任 + 惊叹 |
| 完成后 | 成果 + 惊喜点交付 | 精修图 | 传播素材 |

**汇报话术模板**（自拟版，参考风格）：
```
X 哥，今天第三天，卧室和客厅已经完成。
您上次提到射灯有点暗，已经换好了。
厨房的过期调味料也清掉了，一共 6 样。
明天上午做厨房和主卫，主卫会插花。
```

**要点**：
1. **带称呼**（关系感）
2. **报数字**（做了几样、几个）——具体 = 可信
3. **引用他之前说的话**（"您上次提到…"）——证明你在听
4. **预告下一步**（降低期待波动）
5. **不发长文**（1-2 条/次，见坑点 6）

### C5 极致项目执行标准

#### 豪车毒版：极致家庭深度清洁（6 条）

> **"我们清理花洒时会确保每一个出水孔正常；会帮女孩子擦干净粉底的镜片；
> 会修理好家里的木板、射灯、螺口、充电线；会扔掉过期的药品和食品；
> 每个房间都会准备插花，洗手间也不例外；会给用户煮银耳汤……"**

| # | 极致动作 | 满足的需求 | 传播力 |
|---|---------|-----------|--------|
| 1 | 清理花洒确保每一个出水孔正常 | 洁癖 / 细节控 | 中 |
| 2 | 擦干净粉底/化妆镜镜片 | 女性爱美 | 中 |
| 3 | 修理木板、射灯、螺口、充电线 | 顺手解决小毛病 | 中 |
| 4 | 扔掉过期的药品和食品 | 安全隐患 | 高（安全） |
| 5 | 每个房间准备插花，洗手间也不例外 | 全域无死角 | **高（超预期）** |
| 6 | 给用户煮银耳汤 | 从"打扫"到"照顾" | **最高** |

**规律总结**：
- 第 5、6 条是**超越职责边界**的动作 → 最容易被传播
- 越"跨界"的越震撼
- 每条都要能拍出对比

#### 组织配套

| 岗位 | 人数 | 职责 |
|------|------|------|
| 保洁 | 15 | 极致清洁，6-10 人团队，现场 2-3-7 个工作日 |
| 摄影师 | 5 | **每次外出保洁都配备摄影师**，拍摄保洁前后对比 |

> **"每次外出保洁时都会配备摄影师，在保洁人员工作的时候拍摄留存。
> 我们有足够的自信，今天做的产品足够优秀，才敢『秀』出来。"**

**镜头清单**（每次服务必拍）：
1. 到达时的原始状态（全景）
2. 细节特写（出水孔、镜片、螺口）
3. 施工中（有人影，有动作）
4. 完工对比（同一机位）
5. 成品氛围（插花、银耳汤、鲜花）
6. 客户看到成果的反应（如果客户在场且已授权）

## 阶段 D｜留存与关系

### D1 触点维护

> **"不管是送礼品、还是保洁、家宴、还是朋友圈、公众号、视频等等都是和客户互动的触点。
> 有了触点提供优质的内容，就是在给客户种草，种草多了就占领了用户的心智，
> 不管是自己复购，还是转介绍，都可以第一时间想起。"**

| 触点 | 案例频率 | 内容要求 |
|------|---------|---------|
| 微信朋友圈 | 日更 | 生活 + 服务片段 + 客户反馈（授权后） |
| 短视频 | 公司号 + 个人号日更，抖音为重点 | 服务过程、前后对比 |
| 公众号 | 不固定推送 | 深度内容、行业观点 |
| 直播 | 不定期 | 现场服务、答疑 |
| 服务 | 按权益频次 | 每次都有惊喜点 |
| 礼物 | 每年 5 份 | 见 D2 |

**标准**：每次触点必须**至少让客户"想起你一次"**。

---

### D2 礼物日历（年度 5 份）

| 时点 | 礼物类型 | 设计目的 |
|------|---------|---------|
| 春节 | 纯手写春联 | **"霸占"客户家门口一年广告位** |
| 端午 | 节令礼 | 记忆点 |
| 中秋 | 节令礼 | 记忆点 |
| 客户生日 | 定制礼 | 关键日期触发 |
| 客户纪念日 | 定制礼 | 关键日期触发 |

> **"每年送上纯手写春联，『霸占』客户家门口一年广告位"**
> **"每年固定送 5 份礼物等，促进老客户留存、转化、转化不了还能转介绍"**

**两条设计原则**：
1. **"占位型"礼物 > "消耗型"礼物** —— 摆在客户每天能看到的地方
2. **"手写" > "印刷"** —— 手写传递的关系强度完全不同

**极端延伸（案例原文）**：
> **"甚至不买车了、客户进监狱了，还在送礼。"**

这是"终身关系"的极致表达。

---

### D3 关系人脉经营（"小人物战略"）

> **"与人为善、人与我善，生活中不起眼的『小人物』在自己的私域中也有着不小的话语权。
> 老纪的《保洁团队手册》里第一条就是：『去客户家保洁，一定要先把保安和客户家的住家阿姨
> 关系搞好』。送保安新手机套并帮 ta 的手机贴膜，送保洁阿姨伴手礼以及毛巾、牙刷、牙膏等小礼物，
> 这些善意的举动，使得双方关系发生改变，而因为此类『小人物』的推动从而达成交易的案例比比皆是。"**

**你行业的对应角色**：

| 角色 | 动作 | 效果 |
|------|------|------|
| 保安/门卫 | 送手机套、贴膜、节日礼 | 信息枢纽 |
| 住家阿姨/保姆 | 毛巾、牙刷、牙膏、伴手礼 | 家庭内部影响者 |
| 保洁/服务人员 | 伴手礼 | 执行端口碑 |
| 物业/前台 | 节日礼、日常小照顾 | 场地端影响者 |
| 快递/外卖/司机 | 节日红包、好评引导 | 末端触达 |
| 邻居 | 意外惊喜 | 口碑扩散 |

**执行要求**：
- 写进**服务手册第一条**（案例就是这么做的）
- 有**标准预算**（人均几十元即可，量大）
- 每次上门**都要做**（不是偶尔）

## 阶段 E｜裂变与转化

### E1 触发晒图

**数据**：
> **"根据他们的数据统计，100 个用户基本上 98 个会发朋友圈，
> 极致服务带来的传播推广率高达 98%！"**

**机制不是"求客户发"，是三件事同时发生**：

| 条件 | 做法 |
|------|------|
| 超出预期 | 服务做到客户"忍不住" |
| 有面子 | 素材质量高到客户愿意展示 |
| 有新意 | 每次服务都是新画面，不是重复的 |

**关键时点**：
> **"每次做完保洁，都能看到客户在社群不停发照片、视频，发朋友圈，
> 因为很多服务完全超过了他们的想象。所以，在保洁业务还没做完的时候，
> 就已经开始获取新的流量客户了。"**

**业务未完 → 裂变已始。** 这是效率来源。

---

### E2 转介绍承接

**客户为什么转介绍（三个心理机制）**：
> **"我们觉得客户是发自内心去转发和推荐的，首先他认可我们，然后他希望有更多的人认可我们，
> 他也可以得到一种心理满足。就比如我们去了一家特别好吃的店，就会主动推荐给朋友一样。"**

| 机制 | 你的设计 |
|------|---------|
| 认可 | 服务必须真超预期 |
| 分享的收益 | 让分享有面子（素材好） |
| 心理满足 | 给"值得推荐"的感觉 |

**承接流程**（转介绍后 24 小时内）：

1. 客户推荐后 **2 小时内** 回复（表达重视）
2. 主动给客户"介绍人礼"（增强他的成就感，且不伤关系）
3. 24 小时内联系被推荐人（**不绕过介绍人直接冲**）
4. 见面/服务时**明确提到介绍人**（让他有面子）
5. 成交后**双向回礼**（介绍人和新客户都礼）

**关键**：**不要让介绍人觉得"我帮了忙但没好处还得罪人"。**

---

### E3 转化与复购

**引流款策略**：
> **"卖阿尔法不赚钱，这是引流款，买了这个车后可能还会有其他车的需求，
> 都会继续找他。"**

**多产品矩阵**：
> **"以前我们是 1 个产品卖给 1000 个人，现在是想把 1000 个产品卖给 1 个人。"**

| 层级 | 案例 | 作用 |
|------|------|------|
| 引流款 | 阿尔法（不赚钱） | 拉人进门 |
| 主力 | 豪车 | 70-80% 业绩 |
| 利润款 | 代购飞机、游艇、奢侈品 | 新业务每年翻倍 |
| 场景款 | 老纪蚝宅（餐饮） | **"可能赚不赚钱不打紧，赚的是高净值人脉"** |
| 知识款 | 「私域必修课」「超级连接者的进化论」 | 扩展变现 |

**跨行业映射**：

| 层级 | 你的版本 |
|------|---------|
| 引流款 | 低价体验版服务 / 免费体检 / 基础咨询 |
| 主力 | 核心高客单产品 |
| 利润款 | 高毛利附加服务、周边产品 |
| 场景款 | 私域聚会/沙龙/饭局 |
| 知识款 | 培训、课程、社群会员 |

**外部分享原则**：
> **"我们把这些专业性的东西都交给了第三方，把和汽车不相关的摄影、保洁等由自己来把控品质。"**

| 自己把控 | 交给第三方 |
|---------|-----------|
| 摄影、保洁、**和核心体验相关的一切** | 物流、保险、金融、美容、改装、售后、配件 |

**外部伙伴规模**：约 300 人。

## 附：服务人员行为规范（照抄改写）

### 豪车毒原版三条

> **"我们对保洁人员有很多要求：不能收用户的红包、不能喝用户家的水、不能上用户的洗手间。
> 正是因为这些规定，才能让用户感知到，我们的员工素质、服务水平、团队能力和普通保洁完全不一样。"**

| # | 原版 | 你的行业改写示例 |
|---|------|----------------|
| 1 | 不能收用户的红包 | 不接受客户任何形式的小费/礼品 |
| 2 | 不能喝用户家里的水 | 不使用客户厨房/卫浴的任何物品 |
| 3 | 不能上用户的洗手间 | 不进入客户的私密空间（卫浴、更衣室） |

### 必须补充的另外 5 条（通用版）

| # | 规定 | 理由 |
|---|------|------|
| 4 | 不在客户家接打工作电话 | 隐私 + 专注 |
| 5 | 不翻看客户物品、不打开不必要的柜门抽屉 | 隐私 |
| 6 | 不拍摄未成年人正面、不拍证件、不拍隐私区域 | 合规 |
| 7 | 不与客户建立私人关系（借贷/投资/私下交易） | 品牌地基 |
| 8 | 不用客户信息做二次营销（未经授权） | 合规 |
| 9 | 服务全程不评价客户的车/家/身材/穿着 | 尊重 |

**这 9 条是"高端管家"品牌的地基。** 一次违反，90% 转介绍率的信任会瞬间崩塌。
