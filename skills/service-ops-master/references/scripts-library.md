## 1.1 关于「服务」的定义

> **"我认为同行都没有做的才算是服务。如果一种服务已经有同行做了，那就不是服务，
> 而是义务。"**

> **"我们用这样的信条去做自己本该为用户增加的服务，这个服务才能感动用户，
> 才能让用户感受到不一样的状态。"**

> **"我对保洁的理解也是一样，只有别人没有做过的才是极致深度的清洁，
> 如果别人做过的，也就没有任何亮点和价值了。"**

> **"做得极致的服务才是服务，而不是义务。我们是同行没有做的服务，
> 我们把这个服务做到极致，感动用户。"**

> **"交付之后的服务才叫服务，交付之前都是义务。"**

# 第二部分：可直接使用的模板

> 以下为**基于方法论改写的通用模板**，请按你的行业替换名词。
> 标注 `【】` 的是需要你填写的变量位。

---

## 2.1 客户首次咨询 · 需求诊断

```
X 哥您好，我是【品牌名】的【姓名】。

看到您咨询【具体项目】，先问您几个问题，
好让我们准备得更贴合您和家人的实际需要：

1. 这位服务主要是给谁用？是自己，还是家人/长辈/小朋友？
2. 大概什么场景用？【生日/纪念日/日常/待客/乔迁…】
3. 有没有特别在意或者一定要避开的？
   比如【过敏/不吃辣/不喜欢某类花/家里有宠物/老人身体…】
4. 方便的话，家里大概多少空间/多少人/几辆车这样的规模？

您把这几条回我，我今天之内给您出一版具体的方案和安排。
```

**要点**：
- 一次问 4 个，不要挤牙膏式问
- 场景 + 禁忌 是做出"惊艳"的前提
- 结尾给明确时间承诺（"今天之内"）→ 建立专业感

---

## 2.2 方案确认 · 制造期待

```
X 哥，方案给您整理好了👇

【服务项目】：【服务名】
【时间】：【日期】【时段】
【团队】：【人数】人上门，预计【时长】
【我们准备的】：
  · 【惊喜点1】
  · 【惊喜点2】
  · 【惊喜点3】
【特别为您安排】：【个性化定制点，引用他之前说过的细节】

过程中我会把进度和完成效果实时同步给您。
全部做完您满意之后，结尾还有【收尾动作/小礼物】。

您看时间这边可以吗？
```

**要点**：
- 主动列**惊喜点**（不是列服务项目）→ 预期管理
- **引用他之前说过的话** → 证明你在听
- 结尾留一个"彩蛋" → 期待感

---

## 2.3 服务过程中 · 进度播报

### 2.3.1 开始前

```
X 哥，我这边【姓名】，我们大概【时间】到。
今天主要做【区域1】和【区域2】。
【有一处我特意准备了一下，完工给您看】👌
```

### 2.3.2 过程中（每完成一个区域）

```
X 哥，【区域1】完成了 ✅

顺便跟您说几处细节：
```

```
【前后对比图 ×2】
```

## 2.10 裂变 · 事件营销文案

### 2.10.1 "找 XX" 事件 · 发起方文案

**要点**：

- **给一个具体事由**（不像硬广）
- **点名目标人群**（让对的人对号入座）
- **"先谢过每一位帮忙的朋友"** → 让转发有礼貌的理由

### 2.10.2 找 XX 事件 · 本人回应

- 金额/权益要**相对客单价有冲击力**（案例是 80 万对千万级客单）

## 2.11 危机 · 服务失误处理

### 2.11.1 主动认错（第一时间，不超过 2 小时）

```
X 哥，非常抱歉，这次是我们没做好。

【具体说明哪里没达到您的要求，不找借口】
【已经/马上采取的补救动作】
【补偿方案 —— 具体，不要含糊】

是我们的问题，我们负责到底。
```

**要点**：
1. **2 小时内主动说**，别等客户找
2. **不解释客观原因**（"因为下雨"→ 客户听到的是"借口"）
3. **补偿要具体**（"我送您【X】一次" 而非 "我们会努力改进"）
4. **"我们负责到底"** → 责任明确

### 2.11.2 补救完成后

```
X 哥，这次的问题已经处理好了。
【说明补救结果 + 附上成果/照片】

这次是我们做得不够，让您费心了。
以后这种事不会有了。
```

**要点**：补救后**主动收尾**，不要让客户再"教育"你。

## 2.12 内部 · 服务人员话术

### 2.12.1 上门前给客户发消息（由服务人员本人发）

```
X 哥您好，我是【品牌名】的【姓名】，今天上门做【服务名】。
大概【时间】到，一共【人数】位。

不收您任何红包和心意、不动您家里的水、洗手间我们不会进。

需要提前跟您确认的是：
【禁忌确认一句话】
```

**要点**：
- **主动说三条规矩** → 客户会立刻感受到专业度
- 主动确认禁忌 → 降低服务风险

### 2.12.2 现场发现问题的处理（不问客户，直接解决）

```
（不发消息，直接做：修好/清理/换上/调整）
完工后一并汇报：
"X 哥，有几处我顺手给您处理了，您看还有没有别的需要。"
```

**原则**：**先做后报，不请示。** 请示 = 让客户做决定 = 破坏"极致"感。

## 2.13 内部 · 助理话术（IP 分身）

### 2.13.1 首次加微信通过

```
X 哥您好，我是【品牌名】的【姓名】。
看到您从【渠道】过来的，我这边负责【品类/服务方向】这一块。

先简单了解下您的需求？
您说个大概，我给您一个不用花冤枉钱的建议😊
```

**要点**：
- 说明**来源渠道**（让客户知道为什么加到你）
- 说明**你负责什么**（专业分工感）
- **"给您一个不用花冤枉钱的建议"** → 降低推销感

### 2.13.2 报价

```
X 哥，给您报一下：

【方案A】 标准版：【价格】，包含【清单】
【方案B】 定制版：【价格】，比标准版多【差异化点】

按您刚才说的需求，【我的建议及理由】。
不用急着定，您有想法随时问我。
```

**要点**：
- **永远给两个选项**（锚定效应 + 不逼单）
- **主动给建议**（不把选择题全丢回给客户）
- **"不用急着定"** → 降低压力，反而提升成交率

### 2.13.3 追单（不催单式）

```
X 哥，上次说的【项目】我这边一直记着。

【一个具体的、对他有价值的新信息】
（例：正好我们这个月还有【档期/名额/新权益】）

您看是这周先定下来，还是我再帮您留意着？
```

**要点**：
- 追单要带**新信息**（没有新信息就别追）
- 给"**或者**"选项（而不是"要么…要么…"）
- 全程不提"优惠到期""最后一天"这类虚假稀缺

## 2.14 IP 内容 · 朋友圈素材文案

| 场景 | 文案模板 |
|------|---------|
| 服务日常 | `今天这户【服务名】，最费时间的不是【主任务】，是【意外细节】。` |
| 团队日常 | `团队开了个会，只说一件事：明天起，每单都要多问一句【禁忌清单】。` |
| 客户反馈 | `今天收到客户一句话：【原话】。比发一百条广告都值。` |
| 交付瞬间 | `他/她说想把【交付物】当礼物送出去，我们连夜改成了【方案】。` |
| 价值观 | `我们不做同行都做的事。做了，也只是义务，不是服务。` |
| 团队招募 | `我们不招销售。我们招能把【极致项目】做到极致的人。` |
| 行业观点 | `客户不会为你的服务付费，客户只会为【超越预期】付费。` |

**原则**：朋友圈**不卖货，卖人设**。7 条里 6 条应该跟产品无关。
