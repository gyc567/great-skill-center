# 极致服务运营大师

> **同行在做的服务叫义务，同行没做的服务才叫服务。**

品牌：**AI Skills 创作小店**

本 Skill 提炼自一个真实商业案例：**豪车毒**（创始人纪文华）——一个没有 4S 店、
没有库存、没有展厅、不与客户见面的豪华车线上代购团队，用 **9 名助理 + 15 名保洁
+ 5 名摄影师 + 6~7 名行政** 共 30 余人，靠微信做出 **年流水 10 亿+**，
**转介绍率 90%+**，**转介绍销售额占总销售额近一半**。

## 一、高客单生意的底层结构

**先认清你的生意属于哪一类**，否则方法论会用错地方。

| 维度 | 高频低客单 | **高客单低频** |
|------|------------|---------------|
| 决策成本 | 低 | **高** |
| 信任来源 | 价格/便利 | **服务与关系** |
| 复购周期 | 短 | **很长（可能只有一次）** |
| 获客打法 | 效率/规模 | **信任/裂变** |
| 核心指标 | ROI、复购频次 | **转介绍率、口碑** |

**关键推论：高客单低频的生意，客户的终身价值几乎完全等于「他会不会介绍别人」。**

因为低频意味着他大概率不会再买一次。所以：

```
高客单低频生意 = 一次性成交 + 无限次推荐
                └─ 所以「推荐」就是唯一的复购
```

这决定了整套方法论的重心：**服务不是为了体验，是为了让客户有东西可说、有理由去说。**

## 二、服务信条与三层结构

### 2.1 核心信条

> **"我认为同行都没有做的才算是服务。如果一种服务已经有同行做了，那就不是服务，
> 而是义务。"** —— 豪车毒老纪

这句话是整套体系的判据。**每次想加一项服务，先问：同行做吗？**
- 同行做 → 不做（做了只是拉齐，不构成理由来你这）
- 同行不做 → 做（这就是壁垒）

### 2.2 三层服务结构

```
┌─────────────────────────────────────────────────────┐
│  第三层｜情感层  情绪价值、惊喜、仪式感              │  ← 决定传播
│  "把客户放到心尖上的宠溺"                          │
├─────────────────────────────────────────────────────┤
│  第二层｜管家层  省心、跑腿、代办、接送              │  ← 决定省心
│  "凡是管家工作范围内的事情，我们都会做"            │
├─────────────────────────────────────────────────────┤
│  第一层｜极致层  同行不做的那件事，做到极致          │  ← 决定差异化
│  "极致、深度、独一无二的家庭保洁"                   │
└─────────────────────────────────────────────────────┘
```

**三层缺一不可**：
- 只有第一层（极致）→ 客户觉得你专业，但没理由传播
- 只有第二层（管家）→ 客户觉得你方便，但能被同行复制
- 只有第三层（情感）→ 客户觉得你热情，但没有实质内容
- **三层叠加 → 客户有"故事"可以讲，讲出来别人也想来**

### 2.3 服务宽度 vs 服务深度

老纪的原话逻辑：

> **"用得上或用不上是他的问题，但你必须要给他做选择。"**
> （类比：去海底捞并非把所有服务都用完了，但都能感受到海底捞的服务。）

**这意味着权益清单要"宽"**——即使客户一年只用得上 2 项，
他看到清单时产生的感受是"这家公司为我准备了 26 种被照顾的方式"。

**宽度决定感知价值，深度决定口碑。** 两者都要，且宽度更影响成交时的心理定价。

### 2.4 选"极致项目"的三条标准

不是所有行业都能做保洁。选那个**能进入客户私人空间、能拍出对比、能跨行业复制**的项目：

| 标准 | 说明 | 豪车毒对应 |
|------|------|-----------|
| **能进客户家** | 必须有合法的、私密的、非推销性的接触理由 | 保洁上门 |
| **有前后对比** | 视觉冲击强，客户会忍不住发朋友圈 | 保洁前后对比照 |
| **低频高价值** | 客户一年不可能经常叫，但每次都震撼 | 一年几次深度保洁 |

**跨行业映射表**（把"保洁"换成你行业的等价物）：

| 行业 | 极致项目 | 拍摄素材 |
|------|---------|---------|
| 装修/设计 | 全屋收纳重整 | 改造前后对比 |
| 汽修/保养 | 上门取送车 + 深度焕新 | 焕新前后 |
| 教育/培训 | 上门辅导/陪读 | 学习成果对比 |
| 健身 | 私人教练上门 | 体态前后对比 |
| 宠物 | 上门喂养/洗护 | 宠物状态对比 |
| 软件/订阅 | 一次深度定制实施 | 效率提升数据 |
| 装修建材 | 一次全屋深度除醛 | 检测数据对比 |

> **如果你的行业没有"能进客户家"的项目，找一个"能进客户公司/门店"的等价物。**

### 从清单里能读出的 4 个设计原则

1. **全部围绕"客户的碎片时间"** —— 排队、接送、代办、跑腿
   → 客户最痛的不是钱，是**时间被占用**。省时间 = 最高价值。

2. **服务额度很低但场景很宽** —— 很多是 1-2 次
   → 次数少 = 稀缺感 + 成本可控 + 每次都能做到极致。
   **"一年 2 次" 远好过 "不限次但很敷衍"。**

3. **大量"24 小时"限定** —— 排队、送药、代驾、道路救援
   → 制造**时间稀缺感**，暗示"别人搞不定的事我们搞得定"。

4. **几乎每项都自带拍摄素材** —— 换鲜花、拍全家福、保洁对比照
   → 每一项服务都是**一次内容生产机会**，客户拍照 → 发朋友圈 → 裂变。

## 四、助理模式：把员工变成 IP 分身

### 4.1 组织设计

豪车毒 30 余人的实际配置（**这个比例是重点**）：

| 岗位 | 人数 | 说明 |
|------|------|------|
| 助理 | 9 | 负责汽车销售，**但这辈子没做过汽车，连车都不懂** |
| 保洁 | 15 | 极致服务的执行主体 |
| 摄影师 | 5 | 每次服务都跟拍 |
| 行政 | 6~7 | 后台支持 |
| 传统销售员 | **0** | — |

**为什么"不懂车"的助理能卖豪车？**

> **"他们只要按照公司的『标准化流程 + 高端客户个性化定制』，就可以完成工作。
> 因此，我把他们定义为助理，而不是传统意义上的销售。这些助理全部都是我这个 IP 的『分身』。"**

**核心机制**：把创始人的个人 IP **拆成多个可并行的身份**（主号 + 副号共 80+ 个微信），
由助理用这些身份去和客户对话。客户以为自己在和"老板"沟通，实际对面是受过训练的助理。

> **"我觉得品牌 IP 和个人 IP 对企业的发展都很重要，如果利用好创始人 IP，
> 也是我们在私域流量弯道超车的关键。创始人能放低姿态，和用户走得很近，
> 这种低姿态反而能呈现出他的高度，但一定要把控好尺度。"**

### 4.2 三条铁律（服务人员行为规范）

豪车毒对保洁/服务人员的硬性规定，**这三条本身就是差异化的一部分**：

| # | 规定 | 为什么 |
|---|------|--------|
| 1 | **不能收用户的红包** | 保持关系纯粹 |
| 2 | **不能喝用户家里的水** | 保持专业边界 |
| 3 | **不能上用户的洗手间** | 保持服务者的定位 |

> **"正是因为这些规定，才能让用户感知到，我们的员工素质、服务水平、团队能力
> 和普通保洁完全不一样。"**

**这三条是零成本的护城河。** 任何一家做服务的公司都能立刻加上，而且客户会感知到。

### 4.3 "小人物"战略：向下连接

> **"与人为善、人与我善，生活中不起眼的『小人物』在自己的私域中也有着不小的话语权。
> 老纪的《保洁团队手册》里第一条就是：『去客户家保洁，一定要先把保安和客户家的住家阿姨
> 关系搞好』。"**

具体动作：送保安新手机套并帮 TA 贴膜，送保洁阿姨伴手礼以及毛巾、牙刷、牙膏等小礼物。

**为什么有效**：客户家真正的"信息枢纽"是保安和住家阿姨，不是客户本人。
搞定他们 → 好感传导 → 下一单/转介绍。

**可迁移到任何行业**：
- 物业/门卫/前台 → 送节日礼、帮搬重物
- 快递/外卖/司机 → 节日红包、好评引导
- 客户家的保姆/ nanny → 小礼物、常帮忙
- 办公室前台/行政 → 日常小照顾

## 五、交付体验：颗粒度决定感受

### 5.1 交车/交付瞬间（完整还原）

**交易过程全程实时播报**：

> **"整个交易过程，包括车辆到港、运输到目的城市、交车前极致清洗、改装、镀膜等等，
> 都会实时给客户发送由专业摄影师精心拍摄剪辑的视频和动态照片。"**

**车辆金融/手续全包**：车辆金融贷款事务、车辆交税上牌等事务全部代理，**无需客户出面**。

### 5.2 交付前的仪式化设计

> **"如果客户送车给女友庆生，需要半夜在酒店交付，豪车毒就把车子用巨大的礼盒包装好，
> 安装好灯光，配好音乐，礼盒里放上鲜花气球，让汽车作为礼物，
> 满足客户想象到和没有想象到的惊艳。"**

**关键词：满足客户想象到和没有想象到的惊艳。**
前半句是满足已知需求，后半句是超出预期——**后者才是被传播的部分**。

### 5.3 交付细节清单（可直接抄）

| 类别 | 具体 |
|------|------|
| 车况 | 油是满的 |
| 用品 | 所有能想到的汽车用品配齐 |
| 挂件 | 客户喜欢的吊坠 |
| 纸巾 | 日本进口的纸巾 |
| 饮用水 | 瑞士进口的高端玻璃瓶矿泉水 |
| 提神 | 日本进口医药防疲劳口香糖 |
| 拖鞋 | 航空真皮拖鞋（一大一小两把雨伞：大的放后备箱，小的放驾驶位左边） |
| 内饰 | 收纳箱、真皮脚垫 |
| 鲜花 | 一捧鲜花 + 花语卡片 |
| 应急 | 加满油 + 应急的 200 元加油钱 |
| 音乐 | 客户喜欢的音乐已备好 |

> **"通通都有，甚至还送上一捧鲜花和花语卡片，让客户体验最极致的交车服务。"**

### 5.4 极致保洁的颗粒度标准

这是"极致"的具体定义（**这是全套方法论里最值得抄的部分**）：

> **"我们清理花洒时会确保每一个出水孔正常；会帮女孩子擦干净粉底的镜片；
> 会修理好家里的木板、射灯、螺口、充电线；会扔掉过期的药品和食品；
> 每个房间都会准备插花，洗手间也不例外；会给用户煮银耳汤……"**

**拆解出 6 条"极致"的标准**：

| # | 极致动作 | 满足的需求 |
|---|---------|-----------|
| 1 | 清理花洒确保每一个出水孔正常 | 细节控的洁癖 |
| 2 | 擦干净粉底/化妆镜的镜片 | 女性用户的爱美之心 |
| 3 | 修理木板、射灯、螺口、充电线 | 顺带修好家里的小毛病 |
| 4 | 扔掉过期的药品和食品 | 安全隐患，顺手排除 |
| 5 | 每个房间准备插花，洗手间也不例外 | 全域无死角，超越房间边界 |
| 6 | 给用户煮银耳汤 | 从"打扫"到"照顾"的功能跨越 |

**规律**：极致的本质是**"顺手多做一步"**，而且这一步要在**客户最意想不到的地方**。
第 5 条（洗手间也插花）和第 6 条（煮银耳汤）是典型——最容易被忽略，最容易被记住。

### 5.5 过程中的持续播报

> **"我们会在情感上做一些有温度的东西。比如我们会每晚把保洁的进度、完成效果发给用户，
> 可以让用户更加信任我们。"**

**关键**：不是完工后一次性汇报，而是**过程中持续同步**。
这解决两个问题：① 客户有参与感 ② 客户在家看到干净了，实时产生惊叹和分享欲。

> **"每次做完保洁，都能看到客户在社群不停发照片、视频，发朋友圈，
> 因为很多服务完全超过了他们的想象。所以，在保洁业务还没做完的时候，
> 就已经开始获取新的流量客户了。"**

**注意这个时点**：**业务还没做完，裂变已经开始了。** 这是整个模型的效率来源。

## 六、留存与裂变：让客户成为销售员

### 6.1 核心认知转变

> **"我从来不把用户当用户，我只把用户当成我们的销售员。他们不会背叛我、不会跳槽、
> 不会自己单干，而且会卖力帮我们宣传，为我们介绍新用户。"**

> **"私域流量的本质是人感染人，如果做不到人感染人，今天做的这些服务就失去了任何意义。"**

### 6.2 裂变的四个设计位

```
┌──────────────────────────────────────────────────┐
│ 1. 服务过程可拍摄  →  前后对比图 / 交车大片      │
│ 2. 客户主动晒图    →  朋友圈触发（"必须晒"）    │
│ 3. 关系人脉被经营  →  保安/阿姨/邻居/合作方       │
│ 4. 长期礼物占位    →  每年固定送 5 份礼物         │
└──────────────────────────────────────────────────┘
```

#### 位 1：可拍摄的服务

**规则：每一项服务执行时，都必须能产出一个"值得发朋友圈"的画面。**

执行要点：
- 每次外出服务都**配备摄影师**（不是兼职，是编制内 5 人）
- 拍摄**前后对比**照片（保洁前后、焕新前后）
- 交车由专业摄影师拍**炫酷大片**
- 拍完**主动发客户**，鼓励客户自发分享

> **"想要传播，照片、视频等物料是不能少的。交车时由专业摄影师拍摄炫酷大片，
> 鼓励客户自发分享；存留保洁服务前后对比照片，引发客户的惊叹情绪。"**

#### 位 2：触发朋友圈

关键数据：

> **"根据他们的数据统计，100 个用户基本上 98 个会发朋友圈，
> 极致服务带来的传播推广率高达 98%！"**

**触发机制的设计**（比"求客户发"高明）：
- 服务超出预期到客户**自己忍不住**想发
- 物料质量高到客户**有面子**发
- 每次服务**都产新素材**（不是重复的）

#### 位 3：关系人脉经营

> **"此外，豪车毒注重高端资源的联动，卖高端豪宅、高端奢侈品、高端医疗保险
> 甚至是卖高端旅游出行的，只要手里有高端人脉资源，都可以成为豪车毒共同裂变的伙伴。"**

**你的生态里有哪些人能成为"共同裂变的伙伴"？**
房产中介 / 设计师 / 婚礼策划 / 私人医生 / 健身教练 / 律师 / 会计师 /
高净值社群主理人 / 异业同行

#### 位 4：长期礼物占位

> **"每年固定送 5 份礼物等，促进老客户留存、转化、转化不了还能转介绍"**
> **"每年送上纯手写春联，『霸占』客户家门口一年广告位"**

**"霸占"这个词是关键**——春联不是礼物，是**一年期的家门口广告位**。
客户每天进出都看到你的东西。

**延伸极端做法**（案例原文）：
> **"甚至不买车了、客户进监狱了，还在送礼。"**

这是对"终身关系"的极致表达——**关系不断，服务不断**。

### 6.3 裂变数据模型

老纪公开的流量构成：

| 来源 | 占比 |
|------|------|
| 私域转介绍 | **60%** |
| 创始人个人 IP | 20-30% |
| 其他 | 其余 |

**关键指标**：转介绍率 **90%+**，转介绍销售额占总销售额 **近一半**。

### 6.4 客户转介绍的三个心理机制

> **"我们觉得客户是发自内心去转发和推荐的，首先他认可我们，然后他希望有更多的人认可我们，
> 他也可以得到一种心理满足。就比如我们去了一家特别好吃的店，就会主动推荐给朋友一样。"**

| 机制 | 说明 | 你的设计 |
|------|------|-------------|
| **认可** | 他认同你的服务 | 服务必须真超预期 |
| **分享的收益** | 他希望更多人认可他 | 让他的分享有面子 |
| **心理满足** | 推荐本身让他快乐 | 给他"值得推荐"的感觉 |

**注意**：客户转介绍**不是利益驱动**（没有分销佣金），而是**情感驱动**。
→ 所以你的服务必须给他**情感满足**，而不只是功能价值。

### 6.5 客户分层

原案例数据（2021）：

| 层级 | 数据 |
|------|------|
| 个人微信号 | 180+ 个 |
| 沉淀意向客户 | 20 万 |
| 购买 100 万+ 豪车的高端家庭客户 | 8000+ 组 |
| 其中上市公司企业家/高管 | 140+ 家 |
| 全国"分销管家" | 1000+ 人 |
| 事业合伙人 | 2020 年底全国招募 300 名 |
| 外部第三方合作伙伴 | 约 300 人（物流、保险、金融、美容、改装、售后、配件） |

**"不管你是保安、保洁、客户都是公司的销售员。"** —— 这就是**全民分销模式**。

**外包原则**（重要的成本设计）：
> **"我们把这些专业性的东西都交给了第三方，把和汽车不相关的摄影、保洁等由自己来把控品质。"**

| 自己做的 | 交给第三方的 |
|---------|-------------|
| 摄影、保洁（**和核心体验相关**） | 物流、汽车保险、金融、汽车美容、改装、售后、配件 |

**原则：把"能影响客户感受"的环节握在自己手里，把"纯执行"的环节外包。**

### 6.6 留存触点清单

> **"不管是送礼品、还是保洁、家宴、还是朋友圈、公众号、视频等等都是和客户互动的触点。
> 有了触点提供优质的内容，就是在给客户种草，种草多了就占领了用户的心智，
> 不管是自己复购，还是转介绍，都可以第一时间想起。"**

| 触点类型 | 频率（案例参考） |
|---------|----------------|
| 微信朋友圈/私聊 | 日更 |
| 短视频内容 | 公司号 + 个人号日更，抖音为重点 |
| 公众号图文 | 不固定推送 |
| 直播 | 不定期 |
| 礼物 | 每年固定 5 份 |
| 服务 | 见 SVIP 清单 |

**核心指标**：**触点密度 × 每次触点的质量 = 客户想得起你的概率。**

## 七、IP 与事件营销

### 7.1 创始人 IP 的三个作用

| 作用 | 说明 |
|------|------|
| 信任前置 | 客户相信的不只是公司，是"这个人" |
| 助理分身 | 把 IP 拆成多账号多助理并行 |
| 圈层背书 | 进入高端圈层 = 接触高净值客户 |

**低姿态原则**（老纪原话）：
> **"创始人能放低姿态，和用户走得很近，这种低姿态反而能呈现出他的高度，
> 但一定要把控好尺度。"**

**具体做法**：抖音评论区两天内发 2000+ 条"尊贵的库里南车主"——
**在别人的热点下面刷自己的记忆点**。

### 7.2 事件营销三案例（可复制的结构）

#### 案例 A：互怼事件（1 天 1 亿）

**结构**：蹭大 V 热点 → 双方互发视频 → 流量狂潮

| 环节 | 数据 |
|------|------|
| 涨粉 | 1 天 +2 万 |
| 后台私信 | 8360 条 |
| 导入私域 | 6300 人（**导入率 75.3%**） |
| 48 小时 | 6300 个精准订单 |
| 明确意向订单 | 9.7 亿 |
| 当天真实成交 | 1 亿 |

**可复用点**：
- 找一个**势均力敌**的同量级账号对赌
- 冲突点要**有梗**（"被割韭菜了"）
- 落点必须是**微信**（视频评论区引导 → 私信 → 微信）
- 关键是**导入率**，不是播放量

#### 案例 B：找老纪事件（80 万 → 5000 万）

**结构**：素人发文 → 博主假装寻找 → 创始人砸红包 → 裂变

| 环节 | 数据 |
|------|------|
| 素材来源 | 真实的朋友圈："谁认识老纪，麻烦介绍一下" |
| 操盘 | 私域博主假装在朋友圈找老纪 |
| 老纪动作 | 砸 80 万红包（另一版本记为 380 万）撬动社群裂变 |
| 朋友圈曝光 | 几十万 |
| 找上门的 VC | 100+ |
| 新增私域客户 | 30000+ |
| 成交 | 2 台库里南 + 3 台宾利 + 2 台法拉利 = **5000 万** |

**老纪自述**：
> **"『找老纪』是我策划的第三个营销事件，之前策划的『一条视频 9 亿意向订单』、
> 『尊贵的库里南车主』等话题，都在特定圈层里实现了刷屏。"**

**可复用点**：
- **素材必须是真的**（素人真实发问，不是你自导自演）
- 你只需要**假装在找**，制造稀缺
- 然后**大额砸红包**把"找你的动作"变成"帮你转发"
- 红包金额要**够震撼**（相对于你的客单价，80 万对 1000 万客单是小钱）
- 高 ROI 的根本原因：**私域的垂直度和圈层化**——同圈子的人喜好和消费能力相近，
  扩散像涟漪，且能直接链接到创始人本人

#### 案例 C：付费社群 + 线下分享

| 渠道 | 动作 |
|------|------|
| 付费私董会 | 交 200 万加入现象级网红海参哥的私董会 |
| 行业大会 | 首届中国实体店电商大会《新私域、新服务》主题演讲 |
| 研习社 | 《用服务性思维解锁私域流量运营和服务》线下授课 |
| 企业家游学 | 天下杭商精董班走进公司参访 |
| 企业内训 | 蚂蚁集团、七匹狼、水星家纺等 |
| 计划 | **"我还安排了 100 多场线下分享"** |

**可复用点**：
- 线下分享 = **高净值客户最集中的场合**（一次几百人，全是精准客户）
- 主题命名要**含"新"字**（新私域、新服务）—— 制造新鲜感
- 参访/内训是**最低成本触达老板**的路径

### 7.3 事件营销的通用公式

```
真实素材（别人先说）
   ↓
稀缺感（假装在找 / 制造冲突）
   ↓
大额让利（红包 / 补贴）把"你的事"变成"大家的事"
   ↓
圈层裂变（同圈子涟漪式扩散）
   ↓
强落点（必须导向微信个人号）
   ↓
事件本身成为 IP 记忆点
```

## 八、从 1.0 到 4.0：私域模型的演进

案例中总结的四个版本（**每一版都是能力台阶**）：

### 获客 1.0 —— 被动私域

| 项 | 内容 |
|----|------|
| 整体 | 摸着石头过河 |
| 重点 | 打磨商业模式，做好服务 |
| 获客 | 电话导流 + 口碑传播（早期仅 8 个客户） |
| 服务 | 极致省心：找车、选车、报价、清洗、改装、贷款、上牌全部代办 |
| 超预期 | 加满油、200 元应急加油钱、客户喜欢的音乐、为女友庆生 |
| 关键 | **真正的服务是从交付后才开始的** |

### 获客 2.0 —— 构建全域体系

| 项 | 内容 |
|----|------|
| 整体 | 初步构建全域获客体系 |
| 重点 | 打造创始人 IP，**拓展服务宽度** |
| 全域 | 全网粉丝累计 166 万（截至 2022-06-20） |
| 事业合伙人 | 2020 年开启，全国分销管家 1000+，年底招募 300 名事业合伙人 |
| 服务宽度 | 15 个保洁员帮客户做极致清洁 |
| 关键 | **"我对保洁的理解也是一样，只有别人没有做过的才是极致深度的清洁，
> 如果别人做过的，也就没有任何亮点和价值了。"** |

### 获客 3.0 —— 扩大个人影响力

| 项 | 内容 |
|----|------|
| 重点 | 多种手段趁热打铁，扩大知名度 |
| 事件营销 | 大蓝事件、找老纪事件 |
| 付费社群 | 200 万私董会 |
| 线下 | 演讲、分享会、游学、内训、媒体专访 |
| 关键 | **"找老纪是我策划的第三个营销事件"** |

### 获客 4.0 —— 新赛道

> 案例原文判断：**"4.0 模型还在早期，但整体逻辑和 3.0 类似，只是开启了新的赛道而已。"**
> 4.0 = 老纪蚝宅（餐饮）+ 知识付费（「私域必修课」「超级连接者的进化论」）

### 演进规律（最值得学的一点）

> **"以前我们是 1 个产品卖给 1000 个人，现在是想把 1000 个产品卖给 1 个人。"**

**每加一个新业务，不只是为了赚钱，更是为了给同一批客户增加 1000 个触点。**
→ 触点越多，客户越离不开，转介绍越多。


### 阶段 1：获客

### 阶段 2：沉淀

| 渠道 | 案例做法 |

|---------|------|

| 服务 | 极致服务 + 拓展服务宽度 |
| 餐饮 | 老纪蚝宅——**"虽说打造成了网红店，但可能赚不赚钱不打紧，赚的是高净值人脉"** |

## 十、三条根本原则

### 原则 1：服务升级的目的是关系升级

> **"做服务升级，目的是想做关系的升级，因为只有关系到一定的升华，才是不一样的结果，
> 而私域当中关系的升级往往最简单质朴。"**

**检验标准**：这项服务做完，**你和客户的关系变近了吗？** 没变近就是白做。

### 原则 2：公域拼获客，私域拼维护

> **"我认为公域流量拼的是获客能力，但私域流量拼的是维护用户的能力。"**

**资源分配**：
- 公域：买流量、追热点、做事件
- 私域：**把 20% 的收入花在服务上**（案例中毛利的 20%）

### 原则 3：情绪是底层操作系统

> **"我非常认可梁宁老师说的这句话：人的情绪是底层的操作系统。
> 我们的服务可以控制用户的情绪，我们能了解和发现用户的情绪变化，
> 这可以大大帮助我们做销售以及传播。"**

**实操**：服务过程中持续播报进度（每晚同步）——
不只给结果，给**过程**，让客户在过程中不断产生情绪波动。

## 十一、落地路线图

### 第 1 周：定信条与极致项目

- [ ] 写下你行业的**服务信条**（"同行做 X，我们做 Y"）
- [ ] 用四条标准选出你的**极致项目**（能进客户家 / 有前后对比 / 低频高价值 / 可跨行业复制）
- [ ] 列出该项目的**6 条极致动作**（参考保洁的 6 条）

### 第 2 周：设计权益体系

- [ ] 列出 **26 项**（或至少 20 项）权益，覆盖客户的时间/代办/审美/健康/家庭
- [ ] 标注每项的**频次**（稀缺感）与**是否自带拍摄素材**
- [ ] 找出你的**引流款**（低利润品类，用来拉人）

### 第 3 周：建执行标准

- [ ] 写**服务人员行为规范**（至少 3 条禁止项，参考"不收红包/不喝水/不上洗手间"）
- [ ] 定**过程播报机制**（进度同步的频率与形式）
- [ ] 明确**每个服务都要产出的素材**（照片/视频/对比图）

### 第 4 周：建裂变机制

- [ ] 设计**可拍摄点**清单（每项服务对应产出什么）
- [ ] 做**小人物关系经营**（保安/阿姨/前台/司机/快递）
- [ ] 规划**年度礼物日历**（5 份/年，含"占位"型礼物）

### 第 5-8 周：建 IP 与内容

- [ ] 确定**个人 IP 定位**和低姿态的具体动作
- [ ] 内容节奏：微信日更 + 短视频日更 + 公众号不定期
- [ ] 准备**助理分身**方案（多账号 + 统一话术 + 分工）

### 第 9-12 周：做一次事件营销

- [ ] 找**真实素材**（让用户先说）
- [ ] 设计**稀缺感**（假装在找 / 对赌）
- [ ] 定**让利额度**（相对客单价要有冲击力）
- [ ] 埋**导入落点**（必须导向微信个人号）

## 十二、⚠️ 坑点与边界

### 1. 这套方法论有明确的适用前提

**必须同时满足**：
- 客单价足够高（案例是 80-100 万，你的至少要能撑起一次上门服务的成本）
- 客户本身是高净值/有决策权（企业家、高管、专业人士）
- 服务能进入客户的私人空间或产生强对比视觉
- 决策周期长、信任门槛高

**不满足就别硬套**：
- 低客单高频（拼效率，服务成本摊不平）
- 纯 To C 冲动消费（拼创意，不拼服务）
- 强监管行业（金融、医疗的"上门服务"有合规红线）

### 2. 成本结构必须先算清

案例的成本结构：**毛利的 20% 用在增值服务上**。
- 15 个保洁员服务 8000+ 家庭客户
- 5 个摄影师全程跟拍

**如果你的服务成本超过毛利的 20%，这个模型不成立。**
先做小规模验证：先服务 10 个客户，测出单次服务成本和客户满意度。

### 3. "极致"不能等于"越界"

案例中三条禁止项的逻辑是**保持服务者的专业边界**。

**红线清单**（每个行业自己定，但必须有）：
- 不收客户红包/礼品（保持关系纯粹）
- 不进入客户的私密空间（卫生间、更衣室、卧室无授权不进）
- 不接触客户家庭成员的个人隐私
- 不用客户信息做二次营销（需授权）
- 服务人员不与客户建立私人关系（配偶/借贷/投资）

> **这不只是合规问题，是商业模式的地基。**
> 一旦员工和客户建立私人关系或做出格的事，整个"高端管家"品牌会瞬间崩塌，
> 而且是 90% 转介绍率的崩塌。

### 4. 摄影必须有"客户在场"的授权

拍摄客户家里 → 涉及隐私。**必须**：
- 提前书面/微信确认拍摄范围与用途
- 不拍未成年人正面、不拍身份证件、不拍家庭隐私区域
- 客户家的照片不用于其他客户的展示
- 素材**优先给客户自己发**，再考虑二次使用

### 5. 极致的边际成本会失控

"每一个出水孔都正常"这种标准，熟练后边际成本下降；
但"煮银耳汤""插花"这类是**每次都要发生**的。
**清单要分级**：
- 必做（每次）→ 标准化、可培训
- 选做（按客户画像/预算）→ 提升个性化

### 6. 别把"极致"做成"噪音"

案例的 98% 朋友圈传播率，来自**超出预期**而不是**数量多**。
如果每次服务都发 20 条消息给客户，客户会屏蔽你。
**标准**：每次服务，客户收到 **1-2 条有冲击力的内容**就够。

### 7. 股权/合伙人不等于分销员

案例里"保安、保洁、客户都是公司的销售员"是**荣誉性质**的，
不是分销佣金模式。
真做分销要处理：合规（多层分销涉嫌传销）、税务、结算。
**建议**：先做"推荐有礼"（一次性奖励），不要一上来做多级分销。

### 8. 数据：不要只看服务成本

该盯的指标：

| 指标 | 目标（案例参考） |
|------|-----------------|
| 转介绍率 | 90%+ |
| 转介绍销售额占比 | 近 50% |
| 朋友圈自发分享率 | 98% |
| 私域流量导入率 | 75.3% |
| 客单价 | 80-100 万 |
| 服务成本占毛利 | ≤ 20% |
| 单客服务次数 | 低频（1-2 次/年） |
