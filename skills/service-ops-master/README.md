## 🧬 核心方法论速览

### 服务信条

> 同行都没有做的才算是服务。如果一种服务已经有同行做了，那就不是服务，而是义务。

### 三层结构

```
第三层｜情感层  情绪价值、惊喜、仪式感   → 决定传播
第二层｜管家层  省心、跑腿、代办、接送     → 决定省心
第一层｜极致层  同行不做的那件事，做到极致 → 决定差异化
```

### 极致项目四标准

能进客户家 · 有前后对比 · 低频高价值 · 可跨行业复制

### 裂变四设计位

可拍摄的服务 · 客户主动晒图 · 关系人脉经营 · 长期礼物占位

### 事件营销公式

真实素材 → 稀缺感 → 大额让利 → 圈层裂变 → 微信落点 → IP 记忆点

### 成本红线

增值服务成本 ≤ 毛利 20%（案例的硬指标）

## ⚠️ 使用前请先确认

这套方法论**有明确前提**，不满足时硬套会亏钱：

- ✅ 客单价足够高（能撑起一次上门服务成本）
- ✅ 客户是高净值或有决策权
- ✅ 服务能进入客户私人空间并产生强对比视觉
- ✅ 决策周期长、信任门槛高
- ❌ 低客单高频（拼效率，服务成本摊不平）
- ❌ 强监管行业（金融/医疗上门服务有合规红线）
- ❌ 纯冲动消费（拼创意，不拼服务）

**红线**：一次员工违规（收红包/进客户私密空间/与客户建私人关系），
90% 的转介绍信任会瞬间崩塌。这是品牌地基，不是道德建议。
