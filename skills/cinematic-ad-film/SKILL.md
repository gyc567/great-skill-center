# 电影广告大片生产线 (Cinematic Ad Film)

## 一句话

把一件普通产品，用**电影导演的视觉语言**，拍成"消费不起"的奢侈品级广告大片。

它的对手不是别的产品广告，而是**电影**。用户看完不该记住"这是个杯子"，而该觉得"这像一部电影，只是主角是杯子"。

## 何时使用

- 用户要求"把 X 拍成奢侈品 / 高级感 / 电影感 / 大片 / 概念片 / 品牌片"
- 用户点名某位**导演风格**（诺兰 / 维伦纽瓦 / 王家卫 / 韦斯·安德森 / 芬奇 / 维姆·文德斯…）
- 用户要做"看起来像电影预告片""像 4A 品牌 TVC"的产品视频
- 用户明确要求**先出创意脚本 + 广告语，确认后再生成视频**

## 与 `product-short-video` 的分工（别混用）

| | `product-short-video` | `cinematic-ad-film`（本技能） |
|---|---|---|
| 目标 | 投放转化、带货、A/B 测试 | 作品感、品牌调性、刷屏级大片 |
| 创意 | 6 个方向任选、剧情植入 | **单一强创意**，导演母题驱动 |
| 风格 | 模板化、可批量 | **导演风格锚定**，唯一且强 |
| 后期 | 通用调色 + 金色字幕 | 电影级调色（胶片颗粒/冷调）+ 衬线大字幕 + 管弦配乐 |
| 时长 | 15s / 30s 灵活 | 15s 精修（精确到帧） |

用户要的是"**片**"而不是"**广告**"时，走本技能。

## 七条铁律

1. **先定导演，再定创意。** 风格不是滤镜，是叙事语法。诺兰讲时间、维伦纽瓦讲宏大与敬畏、王家卫讲暧昧与错过——**先选定一个导演**，全片语法从一而终，禁止中途混搭。
2. **先脚本后镜头（最重要）。** 拿到需求**绝不立刻生成画面**。先输出「创意原点 + 广告语候选 + 3 镜分镜脚本」，让用户确认创意与文案，**放行后**才进入关键帧与视频生成。
3. **创意原点 = 导演母题 × 产品本质。** 不写功能，写**命题**。保温杯的本质是"对抗时间流逝"，恰好撞上诺兰一生的母题——于是命题成立：*时间是唯一不可逆的奢侈品，而它，替你留住了温度*。先找这个交点，再谈画面。
4. **一致性锚定。** 先产出「主体设定卡」（产品锚定 + 主角锚定 + 风格锚定 + 负面约束四段固定文本），后续**所有**分镜 prompt 逐字复用；一经启用不得改写。
5. **分层生产。** 精确信息（字幕/价格/Logo/数字）属**确定性层**，全线后期叠加；画面属**生成层**，其 prompt **必须禁止出现文字/Logo**（否则渲染乱码）。生成层越干净，成片越高级。
6. **后期是"电影感"的另一半。** 原始片段只是素材。调色（胶片颗粒 / 冷调 / 暗角）、衬线大字幕（带描边投影）、管弦配乐（有起伏弧线）、精确到帧的时长——**四件套缺一不可**。
7. **全部交付。** 关键帧、分镜片段、最终成片、脚本 md **全部**交付，不得把中间素材当"内部产物"隐藏。

## 全流程（7 阶段）

### Phase 0 · 输入采集与导演选定

确认输入（缺失则主动询问，**不要臆造**）：

- **产品**：是什么、卖点、目标人群、价格带。
- **投放平台与规格**（缺省即默认并告知）：默认 **9:16 竖屏 / 15 秒 / 24fps**。
- **导演风格**：用户指定则用指定；未指定则**给出 3 个最契合该产品的导演风格**（附一句话理由）让用户挑。

### Phase 1 · 创意原点 + 广告语 + 分镜脚本（CRITICAL，必须等用户放行）

一次性交付三样，缺一不可：

1. **创意原点**：一段文字，说清「为什么是这个导演 × 为什么是这个产品」。给出一条**核心命题**（不是卖点罗列）。
   - 可另附 2–3 个备选角度（如"12 小时""陨石"），但**只推进主推那条**。
2. **广告语候选**：主推 2 条 + 备选 3–4 条，按调性排序；末帧价格卡文案（延续系列的定价玩笑，如 `¥9,999 / 仅限受邀者`）。
3. **分镜脚本表**：`镜号 | 时长 | 画面 | 运镜 | 字幕 | 音效`，含转场与音频说明、总时长。3 镜 × 5s 是 15s 的安全结构。

> 输出后**停下等确认**。用户说"就这个"再往下；用户要换角度只重跑本阶段。

### Phase 2 · 主体一致性设定卡

一段可直接粘贴进所有 prompt 的固定文本：

```
产品锚定：<材质、颜色、造型、唯一识别细节，一段固定英文>
主角锚定：<年龄感、发型、服装、气质，一段固定英文；无人物则省略>
风格锚定：<画幅/镜头质感/景深/打光逻辑/调色倾向/运镜质感，一段固定英文>
调色规范：<主色关键词 + 字幕字体与颜色，如 Songti SC Black #F2EFE6>
负面约束：no text, no logo, no watermark, no subtitles, no extra fingers,
          no distorted face, no plastic CG look, <禁止的风格漂移，如 no orange-and-teal grade>
```

写法和导演风格对照见 `references/prompt-recipes.md` 与 `references/director-styles.md`。

### Phase 3 · 分镜脚本 → 关键帧

1. 按分镜表**逐镜生成 9:16 关键帧**：每镜 prompt = `风格锚定 + 产品/主角锚定 + 该镜画面描述 + 负面约束`。**锚定词逐字复用。**
2. 生成后目检：跨镜一致性、光效、有无文字残留；不合格**只重生成该镜**。

### Phase 4 · 图生视频

- 首选**图生视频**（有分镜图时），运镜词写进 prompt：`push-in / dolly-out / slow pan / 微距横移`。**越克制越高级**，忌"快切/闪回/剧烈抖动"（图生视频易崩）。
- 每镜单独生成，时长目标 5s。
- 遇 `JobNumExceed` / 队列繁忙：退避 1–3 分钟重试，**不要改需求**；遇安全拦截：调整措辞后重试，连续失败 2 次即终止并告知用户。

### Phase 5 · 电影级后期（四件套）

统一走 `scripts/assemble_video.py`（见 `references/edit-recipes.md` 详解）：

1. **拼接 + 叠化**：段间 0.5s `xfade`（注意 xfade 会吃掉时长）。
2. **精确时长**：`tpad` 克隆尾帧凑整到目标秒数（3 段补至 5.3333s → 15.000s 整）。
3. **电影级调色**：选用预设 `film`（纪实冷调颗粒）或 `nolan`（IMAX 冷调低饱和）。
4. **衬线大字幕**：Pillow 渲染透明 PNG → overlay + alpha fade；**浅色背景必须加描边+投影**。
5. **管弦配乐**：选有"静→起→顶点→骤停"弧线的段落，`-t` 精确对齐时长。
6. **QC**：`ffprobe` 校验时长/尺寸/码率 + 抽帧目检。

### Phase 6 · 对话迭代（最小化重跑）

| 用户说 | 只重跑 |
|---|---|
| 换创意角点 / 换广告语 | Phase 1（脚本） |
| 换导演风格 | Phase 2 → 4 |
| 某镜画面不满意 | Phase 3 该镜 → Phase 4 该镜 → Phase 5 合成 |
| 字幕太大 / 颜色改一下 | Phase 5（仅字幕） |
| 音乐换一段 / 加淡出 | Phase 5（仅音轨，`-c:v copy`） |
| 整体再"高级"一点 | Phase 5（调色预设 + 字幕描边 + 配乐弧线） |

## 模型与工具映射

| 环节 | 首选 | 备选 |
|---|---|---|
| 关键帧（9:16 电影感） | 高质量文生图 / ImageGen `quality=high` | 图生图保产品还原 |
| 图生视频 | 图生视频模型（`yt-video-2.0` 链路） | 文生视频模型 |
| 人物出镜 | 人物视频模型 | — |
| 剪辑/调色/字幕/时长 | `scripts/assemble_video.py` | 手写 filtergraph |
| 配乐 | 免版税管弦乐（Pixabay / Tunetank） | 站内音乐库 |

## 质量与合规红线

- 禁止涉及未成年人的任何内容；禁止违规内容。
- 保留平台"AI 生成"标识（合规要求），除非用户明确要求且场景允许。
- 统一输出目录（如 `outputs/<项目名>/`），最终回复列出**全部**产物路径。
- 视频生成耗时数分钟，**提前告知用户预期等待时间**。

## 反模式（不要做）

- ❌ 拿到需求直接开生成 → 应先出「创意原点 + 广告语 + 分镜脚本」等确认
- ❌ 创意写成卖点罗列（"保温 12 小时、316 不锈钢…"）→ 应写成**命题**
- ❌ 多镜自由发挥、风格漂移（一会儿诺兰一会儿抖音）→ 应逐字复用设定卡
- ❌ 让生成模型渲染字幕/价格/Logo → 应走确定性层后期叠加
- ❌ 只调色不加配乐/不加字幕描边 → 电影感只剩一半
- ❌ 用户改一句字幕就整条重跑 → 应最小化重跑
