# X 情绪钩子推文方法论

## 心法（一切的核心）

**"你讨厌这个内容，那你就是流量来源。"**

- 情绪即流量：让人产生**强烈情绪**（嫉妒、不爽、震惊、不服、好奇、被冒犯）比让人喜欢更重要。
- 负面互动也是互动：骂、反驳、纠正、阴阳，全部计入算法互动信号，触发 For You 分发。
- 内容不是让所有人喜欢，而是让一部分人**反应强烈**。情绪浓度决定传播半径。
- 评论区是主战场：内容是鱼饵，评论区是收网的地方。作者**不下场控评**，让评论区自然吵起来。

## 执行方法

### 1. 发"招人恨 / 惹眼红"的内容（钩子选题）

- 秀成果 + 反直觉数据：低粉高收入（"粉丝不到200，月入6万"）、AI 自动月入、涨粉速度对比（"超过99%真人账号"）——激发"凭什么是TA / 我不服"。
- 绝对化观点 / 拉踩：断言"XX不行"、"你讨厌XX，你就是XX的转化目标"，制造站队分裂。
- 自曝争议操作：公开"我就是用AI运营的""我就是在引流"——让人忍不住来骂。

### 2. 用 Bot / AI 批量自动运营（铺量测试）

- 高频发帖（30+ 帖起），让算法持续给你试分发；情绪浓度高的选题天然触发更大试分发。
- 数据说话：只看自然流曝光与评论率，快速迭代选题方向，砍掉无情绪反应的内容。

### 3. 评论区留钩子 + 不下场（收流量）

- 内容里刻意留**可攻击的槽点**：夸张数据、绝对结论、无证据的断言、反常识细节。
- 勾子位置：结尾留一句挑衅/反常识（"你讨厌它，你就是它的流量"类），逼人评论。
- 作者绝不下场解释或反驳——每条回复都是新一次算法加权，吵=流量。
- 甄别信号：评论区开骂比例越高，自然流越猛；把"被骂"当正向 KPI。

## 应用到拆解推文（X灵感拆解日报）

拆解推文同样按情绪钩子配方产出，目标是让人看完**忍不住评论**：

1. **数据点睛要扎心**：不用"点赞14万"这种中性描述，用"3,935粉凭什么14万赞——你粉比TA多，赞还没TA零头"。
2. **爆因拆解带不服感**：点破"这种内容能爆，是因为你不爽，你不爽就是流量"，把读者自己也绕进传播逻辑。
3. **方法论给"马上能抄"的动作**：具体到动作（引用爆款+15字震惊话），让读者感觉"我现在就能干"。
4. **结尾留挑衅钩子**：一句话把读者架上（"你上次发帖为什么没人理？因为你没让人不爽"），引评论。
5. **评论区运营**：发布后不控评；对高互动评论可选择性"补一刀"（继续拱火），不解释、不反驳。

## 情绪钩子配方（可复用模板）

| 钩子类型 | 一句话模板 |
|---|---|
| 眼红型 | "X粉的号，凭什么Y万赞——你粉比TA多，赞没TA零头" |
| 不服型 | "都说X不行，可TA靠X月入Y。到底谁不行？" |
| 震惊型 | "只发了11个字，X万人点赞。就因为这11个字" |
| 挑衅型 | "你讨厌这条内容？那它就是为你准备的流量" |
| 反常识型 | "粉丝越少，越容易爆。X平台不看粉丝，看情绪" |

## 红线

- 不造谣、不虚构数据、不人身攻击；"招恨"靠观点和反差，不靠造假。
- 情绪钩子 ≠ 标题党空转：内容必须有真实信息增量，钩子负责让人点开，正文负责让人留下。
