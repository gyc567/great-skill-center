# 内容点子生成器 (Content Ideation)

## Overview

一篇帖子能火，选题占 60%。本 skill 用"支柱 × 格式"矩阵批量生成选题，确保每周不重样、不跑题。

先读取 `voice-builder` 生成的 `voice-profile.md`，然后出选题矩阵。

## When to Use

触发词：
- "想选题" / "今天写什么" / "这周发什么"
- "给我一些内容点子" / "content ideas"
- "选题矩阵" / "本周选题计划"
- 内容枯竭时

## 工作流程

### Step 1: 读取声音档案

用 `mcp_orbitos_vault_read` 读取 `30_知识库/voice-profile.md`，提取用户的内容支柱和边界。

如果档案不存在，提示用户先运行 `voice-builder`。

### Step 2: 确定支柱和格式

**内容支柱**（从 voice-profile 的"常写话题"提取，或让用户确认）：

默认 4 个支柱：
- 支柱 A：专业干货（你的领域知识）
- 支柱 B：个人洞察（你的独特观点）
- 支柱 C：案例故事（你/他人的经历）
- 支柱 D：资源推荐（工具/书/方法论）

**8 种格式**：

| # | 格式 | 模板 | 适合 |
|---|------|------|------|
| 1 | 反常识观点 | "[常见认知]是错的。真正的原因是..." | 建立权威 |
| 2 | 实战拆解 | "我是怎么做到 X 的？分 3 步..." | 教程型 |
| 3 | 数据洞察 | "这个数字告诉我一个秘密..." | 引人好奇 |
| 4 | 清单汇总 | "搞 X 的 7 个必备..." | 高收藏 |
| 5 | 对比分析 | "A vs B：哪个更适合你？" | 决策帮助 |
| 6 | 故事叙事 | "3 年前我...，今天我..." | 情感共鸣 |
| 7 | 提问互动 | "你觉得 X 是 A 还是 B？" | 评论驱动 |
| 8 | 预告/悬念 | "我最近发现一个惊人的..." | 留存关注 |

### Step 3: 生成矩阵

支柱 × 格式 = 至少 32 个选题。输出为表格：

```
支柱A（专业干货）       支柱B（个人洞察）       支柱C（案例故事）       支柱D（资源推荐）
1.反常识 [选题]         [选题]                 [选题]                 [选题]
2.拆解   [选题]         [选题]                 [选题]                 [选题]
3.数据   [选题]         [选题]                 [选题]                 [选题]
...
```

每个选题写成**一句话钩子**，不要展开。

### Step 4: 精选本周 TOP 5

从矩阵中选出 5 个最有潜力的选题，按优先级排序。评估标准：
- 是否紧贴热点？（能借势的优先）
- 是否包含强烈情绪？（愤怒/惊讶/共鸣）
- 是否对读者有直接价值？

输出格式：
```
## 本周精选 TOP 5

1. [最推荐] [格式] [一句话钩子]
   理由：[为什么这个会火]

2. [格式] [一句话钩子]
   理由：[...]
...
```

### Step 5: 可选 — 热点借势

如果用户想结合热点，用 `web_search`（或浏览器访问热搜榜）找当前 3 个最热话题，然后标注哪些可以融入已生成的选题。

## Common Pitfalls

1. **支柱太宽泛**：如果用户只有一个大领域，帮他拆成 4 个子角度，而不是全归到一个支柱。
2. **选题太像**：检查每个格子是否真的有差异化角度，避免换个说法凑数。
3. **忽略用户边界**：voice-profile 里写的"避雷话题"绝对不能出现在选题里。
4. **选题太抽象**：每个选题必须具体到"这句话发出去读者会停下来看"的程度。

## Verification Checklist

- [ ] voice-profile 已读取
- [ ] 4×8 矩阵完整（至少 32 个选题）
- [ ] 本周 TOP 5 已精选并标注理由
- [ ] 选题之间有明确差异度
- [ ] 未触碰避雷话题
- [ ] 结果已保存到 vault（可选：`30_知识库/选题矩阵-YYYY-WXX.md`）
