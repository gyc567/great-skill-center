> 一句话结论：**头部的开头不是「炸」，是「质感 + 代入」**：一个电影级质感的主画面慢慢推进，配一句观众一秒就认出自己的话，底下是一首正在火的氛围配乐。

## 画面：质感压倒一切

- **6/8 是 3D 渲染或电影级光影**：熵增是暗房间里窗光慢慢亮起；运气的形状是一颗真实材质的 3D 骰子从画外翻滚进来、落地有阴影；虚无主义是聚光灯下一群 3D 人偶；抖腿是办公桌下一条真实质感的腿、镜头慢推；月老是精致的扁平插画加星空。共同点：**有真实光源、阴影、景深 / 雾气、材质**，构图像电影截图。
- **一个主画面，慢推或一个主动作**：前 3 秒基本只有一个镜头、一个主体、一个动作（灯亮、骰子落地、镜头推近），不是满屏乱动。唯一的快节奏例外是虚无主义：0.5 秒一问「为什么要学习？上班？赚钱？努力？」，画面跟着换。
- **画面不一定要复杂**：焦虑的本质只有白底聊天气泡（「你醒了吗」「嗯」「你生气了吗」「当然没有，怎么了」），照样 38.8 万赞——**代入感比炫技重要**。
- **字幕**：一行，居中偏下，关键词金色或红色高亮；第 0.3 秒内就出现。
- **我们之前输在哪**：Canvas 2D 手画的线条、圆、方块、火柴人，没有光影材质，一眼就是「PPT 动画」。

## 第一句：生活里的一个具体瞬间

- 头部第一句：「房间不打扫，就会落满灰」「骰子落下之前，谁也不知道答案」「为什么要学习？为什么上班？」「你醒了吗？嗯」「这条腿，正在救他的命」「同样的 8 个人，同样的心意」。
- 规律：**观众一秒认出自己的一个场景 / 一个疑问**，平静陈述，不喊、不警告、不说「能救命」。悬念来自「这和我有关，接下来要说什么」。
- 反例（我们做过的）：「数清闪电和雷声之间那几秒，关键时候能救命」——喊口号、和观众此刻的生活无关。

## 声音

- **5/8 用同一首配乐**：《千年之后（氛围版）》（和乐府，抖音曲库）。运气的形状、月老的算法明确标注；熵增、没有回报的努力、抖腿标「原声」，但前 10 秒响度曲线和它完全一致（-9 -9 -14 -14 -10 -8……），是把它混进了视频。氛围钢琴 + 弦乐，开头即进主旋律，不铺前奏。
- **前 4 秒基本没有人声**：6/8 前 4 秒只有配乐 + 字幕（虚无主义 8.7 秒才开口、五次温柔 5.3 秒）；有人声的抖腿、焦虑也是配乐撑底。
- 和用户自己后台数据「有配音更好」不矛盾：**开头用配乐 + 字幕钩住，人声在 0.3–1 秒内跟上**；或者整段配音但配乐音量够、质感够。两种都做样片让用户比。
- **版权**：曲库歌曲要在抖音发布页「添加音乐」里选（平台授权）；本地样片用原片配乐做对比只限内部预览，不进成片文件。

## 做开头的检查表

- [ ] 第 0 帧像一张电影截图：有光源、阴影、景深或雾、材质；不是平面色块
- [ ] 一个主体、一个主动作或一个慢推镜头
- [ ] 第一句是观众一秒认出自己的场景 / 疑问，0.3 秒内上字幕
- [ ] 配乐第 0 秒就是有情绪的主旋律（氛围钢琴 / 弦乐），不是鼓点和炸雷
- [ ] 缩到手机尺寸看第 0 帧：主体一眼可辨

**开头 5 秒四拍（2026-10-26 和用户讨论后定，对标许先森Ai）**，做开头时逐拍对：

- [ ] **张力帧（第 0 帧）**：画面完整，不从黑屏淡入，而且自带一个错位或冲突（人形站在对不齐的标准框里、数字已经亮着、一个东西正要出事），让人一眼觉得这里有事
- [ ] **你（0.3～2 秒）**：第一句用你做主语，一句大白话：直接问观众（你觉得……会……吗），或直接说出一个和观众认知相反的事实；不要长串定语和书面词（抖音观众偏下沉，2026-10-28 用户定）；主体跟着第一个词动，不等
- [ ] **惊艳（3 秒内）**：一个尺度变化或变形镜头，是全片投入最多的一个：镜头猛地拉远揭示你只是几千个里的一个、粒子聚成主体、物体爆开或剖开
- [ ] **反转（5 秒内）**：反常识的结果和数字被念到的那一拍，画面一收、一停、一放：收暗 0.5 秒，定格 3 帧，砸出大号数字并配冲击音；只给结果，原因留着，后面接为什么

## 画面怎么做到这个质感（2026-10-23 样片实测）

同一个钩子（「眼睛都快睁不开了，你手里的屏幕还亮着。」）试了三条路，样片在 `~/Desktop/video/vibe-video/_samples/bedtime/`：

| 路线 | 做法 | 结论 |
|---|---|---|
| **AI 剧照 + 代码运动（主推）** | `space-gzh-cover/scripts/gen_image.py`（gpt-image-2）生成 16:9 电影剧照当主画面，代码只加镜头慢推（1.0→1.1）、光源呼吸、光束里的飘尘、暗角、胶片颗粒、字幕 | 一张图就到头部水准；人物、场景、光影都真实。提示词写「Cinematic film still, 16:9 … shallow depth of field, 35mm anamorphic, teal and amber color grade, soft film grain, photorealistic … No text」。中转站偶发 500 / 超时，加重试循环 |
| 极简界面（焦虑式） | 代码画手机聊天界面，镜头贴近、慢慢拉远，时间飞跳、下面视频流刷起来 | 便宜、可读、代入感强；适合「消息、时间、通知」类钩子。镜头必须贴近（手机占画面大半），第 0 帧就要有第一条消息 |
| 纯代码 3D（Three.js） | 本地装 three@0.160 + esbuild 打成 IIFE（render.py 走 file://，ES 模块不能直接加载） | **人物和室内场景做不出电影感**：基础几何体拼出来的人像玩具，调了两轮仍远不如 AI 剧照。只在单个物体（骰子、硬币、零件）且需要真实运动时用 |

**出图渠道（2026-10-24）**：默认用 `scripts/agy_image.py`（本地 agy，走用户自己的 Google 账号，免费，自带重试和全机 3 路并发锁，出 1376x768 再放大到 1920x1080）。taluna 中转站（`space-gzh-cover/scripts/gen_image.py`，用户自己的 xhs-cover key）是备用渠道：agy 在等额度窗口时可以用它补图；余额耗尽时会报 403 insufficient_user_quota，那时就只能等 agy；公司的 ARTGEN key 和 Rezona 出图 MCP 不能用于这个号。

Canvas 2D 手画的线条、色块、火柴人**不再当开头主画面用**，只做信息层（字幕、数字、标注）。

**用户 2026-10-23 看完样片拍板**：样片 1（AI 剧照 + 代码运动 + 配音）和样片 3（极简聊天界面 + 配音）都可以用；以后开头二选一，人物 / 场景类用 AI 剧照，消息 / 时间 / 通知类用聊天界面，都带配音。

## 对标二：许先森Ai（2026-10-26 拆，用户认可他的原则）

账号 1.9 万粉，10 条作品，前四条 1.1 万～11.7 万赞。全部横版、无配音、只有配乐和字幕，用 Claude Code 写代码做 3D 动画渲染。10 条原片、逐条抽帧、数据和完整拆解在 `~/Desktop/video/vibe-video/_refs/许先森Ai/`（`拆解.md`）。他自己总结的规律，和他的数据对得上的部分：

- **开头**：第 0 帧就是完整画面（地球、两座城市已经亮着），不从黑屏慢慢亮起来，要亮也在 0.3 秒内完成；第一句就把反常识的问题甩出来（你在上海发一张照片，洛杉矶的朋友 0.07 秒就收到了，它是怎么过去的）；2～3 秒时一个金色大数字砸进来。另一种开法是从你身边的动作切到原理：第一帧是手指在刷手机（你每天都在重复这个动作），3 秒切到斯金纳的鸽子（70 年前，一只鸽子也在做同一件事）。

- **画面跟字幕**：每换一条字幕画面就动，执行标准写在 craft-rules.md，检查用 `scripts/still_check.py`。他的爆款每分钟静止超过 2 秒的段落 0～2.2 段，扑街的约 6 段。

- **时长**：四条爆款 115～161 秒，后面做到 204～270 秒的，除两条外都掉了；他自己没提这一条，但比选题规律还整齐。

- **纯代码 3D 的另一条路**：上面实测说 Three.js 拼的人物和室内像玩具，那是在追写实。他不追写实，把主体做成金色发光粒子填充的轮廓（鸽子、手指、大脑、地球），空间用白色细线框搭（斯金纳箱），黑底加辉光，一个主体贯穿全片、镜头不停推拉旋转，整片只切 0～11 次镜头。质感来自光和粒子，不来自建模，所以代码稳定做得出来，也天然适合系列化。人物只用手、剪影或真人黑白照片（科学家出场时配宋体名片）。风格配方和模板在风格库 `_styles/暗金粒子/`。
