# 背景音乐说明

本目录用于存放背景音乐文件。

## 推荐音乐

### 商务风格
- 平稳、专业
- 节奏适中
- 适合产品发布、公司介绍

### 创意风格
- 活泼、轻快
- 节奏感强
- 适合创意展示、品牌故事

### 科技风格
- 现代、电子感
- 节奏明快
- 适合科技产品、创新介绍

## 使用方法

1. 将音乐文件放入此目录
2. 命名为 `background.mp3`
3. ppt-roadshow-generator 会自动使用此音乐

## 注意事项

- 确保音乐版权清晰
- 建议使用免费音乐库
- 音乐时长应与视频时长匹配
- 音量适中，不干扰配音
