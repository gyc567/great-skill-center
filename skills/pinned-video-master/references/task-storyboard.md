# 分镜与画面设计（task-storyboard）

## 目的
把逐字稿拆成可执行的分镜表：每一句对应什么画面、字幕怎么断、镜头怎么动。

## 前置
已有一份确认过的逐字稿（来自 `task-script.md`）。

## 步骤

### 1. 对齐时间轴
按五段结构给每句分配秒数，总和必须等于 30s（±0.5s）。
语速基准：中文约 4.5 字/秒，英文约 2.5 词/秒。

### 2. 每句三个字段

| 字段 | 说明 | 例子 |
|---|---|---|
| 画面 | 主体在做什么 / 镜头看到什么 | 「中景，桌面有笔记本和数据线，手指在敲键盘」 |
| 台词 | 该时间段说的话 | 「我做了六年外贸……」 |
| 字幕 | 断句后的字幕文本 | 「做了六年外贸 / 供过 300 家工厂」 |

### 3. 视觉可信度原则
数字人视频最容易假的地方是「背景像广告」。三条：
- **真实工位**：键盘、纸质笔记本、贴满便利贴的墙，比整洁空白背景可信。
- **手部入镜**：说话时手在动，显著降低 AI 感。
- **不要摆拍**：避免双手交叉、避免直视镜头念稿的姿势。

### 4. 字幕断句
- 每屏 ≤14 个中文字 / 8 个英文词。
- 断在语义边界，不在词中间断。
- 关键词（年份、数字、身份词）单独成屏并加粗。

### 5. 交付
输出 `templates/storyboard-template.md` 结构的分镜表：

```
| # | 时间 | 画面 | 台词 | 字幕 |
|---|------|------|------|------|
| 1 | 0-3s | ... | ... | ... |
```

## 自检
- [ ] 时间总和 = 30s
- [ ] 每句都有具体画面，不是「人物出镜」这种空描述
- [ ] 至少 2 处手部/工作场景入镜
- [ ] 字幕每屏 ≤14 中文字
- [ ] 关键数字单独成屏
