# 新手入门（中文）

## 这是什么
一个把你的个人经历变成 **30 秒置顶视频** 的技能。

刷到你主页的陌生人，看完这条视频就知道：你是谁、你干过什么、你能帮他做什么。
对个人 IP 创始人、知识博主、顾问教练特别有用——一条视频省掉十次自我介绍。

## 怎么用（三步）

### 第一步：建档案（必做，约 3~5 分钟）
第一次使用需要建一份你的个人档案（`pinned-dossier.md`），包含六块信息：
身份、过去经历、现在在做什么、能提供什么服务、可信证据、平台风格。

建档时我会**一次问一个问题**，你只管答，缺的部分我标「待补」——不会替你编。
档案只存在你自己的工作目录，用来生成脚本，不上传第三方（生成成片时会用到你授权的生成服务）。

### 第二步：出脚本
我按 30 秒五段结构写逐字稿：

```
钩子 0-3s → 身份 3-8s → 背书 8-20s → 现状 20-27s → 价值+CTA 27-30s
```

中文上限 90 字，同时给英文版（不是直译，按英文语感重写）。

### 第三步：出片（可选）
确认脚本后，我用 HeyGen 生成数字人视频（需要你自己的 HeyGen Key）。
没装 HeyGen 也不影响——脚本 + 分镜表本身就能拿去剪映/腾讯智影用。

## 常见问题

**Q：一定要建档案吗？**
建议建。不建我也能给你一版临时脚本，但会标「无档案、低置信度」，也不会沉淀到下次。

**Q：数字会不会很假？**
会，所以有质量体检环节：可信度表 + 活人感表 + 迭代动作表，最多迭代 2 轮。
嫌假可以直接用脚本去剪映真人剪辑。

**Q：能保证流量吗？**
不能。技能负责让内容可信、具体、像人，不负责流量承诺。

**Q：我的经历很普通，能做吗？**
普通经历也能做——钩子不需要逆天，真实的具体细节比漂亮话有效。

## 快捷指令
- 「开始建档」→ 进入第一步
- 「帮我写脚本」→ 建档后进入第二步
- 「直接出片」→ 跳过确认直接生成（不推荐）
- 「体检一下」→ 对已有脚本做质量体检
