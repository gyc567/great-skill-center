# 脚本与口播成稿（task-script）

## 目的
产出一条 30 秒、可信、有活人感的逐字稿。

## 前置
档案为 `provisional` 或 `confirmed` 且校验通过。若缺 `history` 或 `offering`，脚本无法成立——
回到 `task-intake.md` 补齐。

## 步骤

### 1. 先定钩子
钩子是全片最贵的一段。四个方向，选一个：

| 方向 | 模板 | 适用 |
|---|---|---|
| 人群点名 | 「如果你也 [具体处境]，这条是给你的。」 | 有明确受众 |
| 反常识 | 「大部分人以为 [普遍认知]，其实 [真相]。」 | 有行业观点 |
| 身份反差 | 「我 [现在的身份]，但 3 年前我在 [完全不同的领域]。」 | 有跨界经历 |
| 成绩前置 | 「[数字结果]，背后是我 [具体做法]。」 | 有硬数字 |

**红线**：钩子不能是「大家好我是XXX」「很高兴认识大家」这类自我介绍式开场，
不能用「震惊」「99%的人不知道」这类浮夸套路。

### 2. 按五段结构写逐字稿
| 段 | 时长 | 字数上限（中/英） |
|---|---|---|
| 钩子 | 0–3s | 12 字 / 5 词 |
| 身份 | 3–8s | 20 字 / 9 词 |
| 背书 | 8–20s | 40 字 / 25 词 |
| 现状 | 20–27s | 22 字 / 12 词 |
| 价值+CTA | 27–30s | 20 字 / 12 词 |

总量：中文 ≤90 字，英文 ≤75 词。超出就砍，不是加。

### 3. 口头可读性检查
写完念一遍（英文用 TTS 念）：
- 有没有念不顺的长句？改成短句。
- 有没有书面语？「进行」「相关」「方面」→ 口语词。
- 数字要不要念？写「三年」而不是「3年」更自然。

### 4. 双语版本
用户语言为中文时，同时给英文版（或反之）。英文版**不是逐字翻译**，是同一条意思按英文语感重写。
句式更短、动词更主动。

### 5. 交付
输出格式：

```
【30秒置顶视频脚本 · 中文】
钩子（0-3s）
身份（3-8s）
背书（8-20s）
现状（20-27s）
价值+CTA（27-30s）

全文字数：XX 字（上限 90）
待补项：（列出档案里标「待补」的模块对应的空缺）

【English Version】
...
Word count: XX (max 75)
```

同时输出 `templates/script-template.md` 结构化版本，供分镜阶段使用。

## 自检
- [ ] 钩子不是自我介绍
- [ ] 每一条经历都能追溯到档案原文
- [ ] 没有编造的数字、客户名、资历
- [ ] 中文字数 ≤90，英文词数 ≤75
- [ ] 有一句具体的服务 + 一句 CTA
- [ ] 没有「震惊」「必看」「99%」等浮夸词

## 边界
- 不承诺流量、涨粉、转化率。
- 不写医疗、金融收益、绝对化用语。
- 不在用户确认前进入生成环节。
