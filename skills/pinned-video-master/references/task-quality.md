# 质量检测与迭代（task-quality）

## 目的
体检一条置顶视频，判断它是否真的建立了信任、有没有活人感。

## 可信度体检表（内容层）

| 检查项 | 通过标准 | 常见问题 |
|---|---|---|
| 经历可追溯 | 每条经历都能追溯到档案原文 | 编造年份、夸大成就 |
| 数字有出处 | 每个数字在档案 `proof` 里 | 「服务过 1000+ 客户」但档案里没有 |
| 身份具体 | 身份 + 领域，不是「资深专家」 | 头衔党、无行业指向 |
| 服务明确 | 一个具体服务 + 一句 CTA | 「想进私域找我」太模糊 |
| 无绝对化 | 无「最」「第一」「保证」 | 行业套话 |

## 活人感体检表（表达层）

| 检查项 | 通过标准 | 常见问题 |
|---|---|---|
| 钩子非自我介绍 | 前 3 秒指向人群或反常识 | 「大家好我是……」 |
| 语速自然 | 听感不赶，留有呼吸 | 全程同一速度、无停顿 |
| 有口语颗粒 | 出现具体动词、具体场景 | 全是抽象名词（「赋能」「闭环」） |
| 画面有生活痕迹 | 至少 2 处工位/手部/实物 | 纯背景板、人物居中不动 |
| 眼神与节奏 | 有轻微的呼吸和点头 | 眼珠不动、机械匀速 |

## 迭代动作对照

| 问题 | 迭代动作 |
|---|---|
| 假 | 换更生活化的形象；把背景从纯色改成真实工位 |
| 快 | `speed` 调到 0.95；删掉 10% 的字 |
| 慢 | `speed` 调到 1.05；钩子压到 2s |
| 钩子弱 | 换钩子方向（人群点名 ↔ 反常识 ↔ 身份反差） |
| 背书空 | 补 `proof` 模块；用过程代替数字 |
| 结尾硬 | 把 CTA 从「关注我」改成具体动作（「评论区扣『清单』」） |

## 迭代预算
单条视频最多迭代 **2 轮**。第 2 轮仍不理想时，明确告诉用户剩余问题与可选路径
（换形象 / 改钩子 / 补档案 / 真人出镜），不无限重试消耗配额。

## 交付
```
体检结果：X/10 项通过
✅ 通过项：...
⚠️ 待改进项：...
🔁 建议迭代：动作 + 预期效果
```

## 边界
- 不承诺「改了就能爆」。
- 不虚构用户数据或播放量反馈。
