# SPEC — 个人 IP 置顶视频生成大师

## 1. 目标

把用户个人经历档案，编译成 30 秒、可信、有活人感的置顶视频成片。

## 2. 输入

### 2.1 档案（六模块，缺一不可）

| 模块 | 键 | 内容 | 缺失处理 |
|---|---|---|---|
| 身份 | `identity` | 姓名、领域、一句话身份 | 标「待补」，脚本身份句留白 |
| 经历 | `history` | 2~3 条（年份+角色+成就） | 不足 2 条时背书段改用「现在」 |
| 现状 | `current` | 现在在做什么 | 标「待补」 |
| 服务 | `offering` | 服务/产品 + 合作方式 | 标「待补」，价值段改用软 CTA |
| 证据 | `proof` | 数字、客户类型、作品、资质 | 标「待补」→ 不放数字背书 |
| 平台 | `presence` | 平台、语言、风格、形象、音色、画幅 | 默认 中文 / 9:16 |

### 2.2 生成参数

| 参数 | 来源 | 默认 |
|---|---|---|
| `avatar_id` | HeyGen Studio → Avatars | 必填 |
| `voice_id` | HeyGen Studio → Voices | 必填 |
| `dimension` | 档案 `presence` | 1080×1920 |
| `language` | 档案 `presence` | `zh` |
| `speed` | 用户指令 | 1.0（建议 0.95~1.05） |
| `caption` | 用户指令 | false |

## 3. 输出

### 3.1 脚本

| 段 | 时间 | 中文上限 | 英文上限 |
|---|---|---|---|
| 钩子 | 0–3s | 12 字 | 5 词 |
| 身份 | 3–8s | 20 字 | 9 词 |
| 背书 | 8–20s | 40 字 | 25 词 |
| 现状 | 20–27s | 22 字 | 12 词 |
| 价值+CTA | 27–30s | 20 字 | 12 词 |
| **合计** | 30s | **90 字** | **75 词** |

### 3.2 分镜表

字段：时间 / 画面 / 台词 / 字幕。时间总和 = 30s ± 0.5s。字幕每屏 ≤14 中文字。

### 3.3 成片

- 文件：MP4，默认路径 `out/pinned-video.mp4`
- 报告：时长、分辨率、形象 ID、音色 ID、建议复核位置

## 4. 约束

### 4.1 强制门（不可跳过）
1. 脚本已展示并获用户一次明确确认
2. 用户明确授权使用其形象/声音
3. 档案 `presence` 已记录形象偏好

### 4.2 内容红线
- 禁止编造经历、职级、客户名、收益、证书编号
- 禁止「最」「第一」「唯一」「保证」等绝对化用语
- 禁止医疗、金融收益承诺
- 禁止「震惊」「必看」「99%」等浮夸钩子
- 禁止以恐惧、羞耻、群体对立制造注意力

### 4.3 钩子红线
不得以「大家好我是…」「欢迎来到…」开场。

## 5. API 契约

### 5.1 创建
```
POST https://api.heygen.com/v2/video/generate
Header: X-Api-Key: $HEYGEN_API_KEY
```
```json
{
  "video_inputs": [{
    "character": {
      "type": "avatar",
      "avatar_id": "<ID>",
      "avatar_style": "normal",
      "voice": {
        "type": "audio",
        "input_text": "<完整口播>",
        "voice_id": "<ID>",
        "speed": 1.0
      }
    },
    "background": {"type": "color", "value": "#FFFFFF"}
  }],
  "dimension": {"width": 1080, "height": 1920},
  "language": "zh",
  "caption": false
}
```

### 5.2 查询
```
GET https://api.heygen.com/v2/video/{video_id}
```
`status` ∈ `waiting | processing | completed | failed`。轮询间隔 10s，超时 900s。

### 5.3 错误码
| HTTP | 含义 | 处理 |
|---|---|---|
| 401 | Key 无效 | 提示重新获取 `HEYGEN_API_KEY` |
| 402/429 | 配额不足 | 提示充值或改用免费额度 |
| 5xx | 服务端错误 | 重试，最多 3 次 |

## 6. 体检规则（pv-check.py）

### 6.1 阻塞项
- 档案状态 `in_progress`
- 档案缺模块
- 钩子含自我介绍式开场
- 未提供档案 / 脚本路径

### 6.2 提醒项
- 档案模块为空或全为「待补」
- 脚本段落少于 5 段
- 浮夸词 / 绝对化用语
- 未检测到 CTA
- 数字在档案中找不到出处
- 中文字数 > 90 或英文词数 > 75

### 6.3 数字溯源范围
`proof` + `history` + `current` + `offering` 任一模块出现即视为有出处。
年份（19xx/20xx）与结构数字（0/3/5/8/20/27/30）不计入。

## 7. 迭代预算

单条视频最多迭代 **2 轮**。第 2 轮仍不理想时，输出剩余问题与可选路径，不无限重试。
