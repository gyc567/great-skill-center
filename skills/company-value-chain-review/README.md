# 企业价值链复盘 (company-value-chain-review)

> **一家公司究竟靠什么活？价值通过哪条经营链变成现金？**
> 两层结构：企业经济性 + 价值到现金的经营链。

## 🎯 只回答两个问题

1. **这家企业靠什么活？**
2. **哪条核心经营链把价值变成现金？**

> ❌ 不从公司历史、使命宣言、组织架构或项目清单开始。

---

## 📐 两层结构

### Layer 1 —— 企业经济性（谁付钱、为什么付钱）

对每家公司回答：

- 谁付钱？
- 为什么这个客户要付钱？
- 收入怎么产生：产品销售 / 订阅 / 佣金 / 价差 / 保费 / 广告 / 服务费 / 授权 / 融资？
- 钱主要花在哪？
- 哪个业务创造最多毛利或营业利润（如已披露）？
- 哪个业务即使不是已证实的利润源，也**战略上不可或缺**？
- 最重要的业务风险是什么？

**结尾必须压缩成一句：**

> 这家公司本质上用 **[核心能力/机制]** 帮助 **[客户]** 解决 **[重要问题]**，从而赚取 **[什么样的钱]**。

> ❌ 不用「提供优质服务」「为用户创造价值」这种空话。

### Layer 2 —— 核心经营链（价值到现金）

通用骨架（起点，不是模板）：

> 客户需求 → 获客/销售 → 产品或服务交付 → 风险/质量控制 → 计费/回款 → 留存/复购

**按行业改造**，例如：

| 行业 | 链条 |
|------|------|
| 保险 | 产品设计与定价 → 渠道销售 → 承保 → 保单服务 → 理赔 → 续保 |
| 汽车 | 用户洞察 → 车型定义 → 研发与采购 → 制造 → 销售 → 交付与服务 → 复购/转介绍 |
| 证券 | 客户获取 → 开户/入金 → 交易或投顾执行 → 风控合规 → 清算 → 客户资产沉淀或交易活跃 |

然后标出：
- 哪一步**主要决定收入**？
- 哪一步**主要决定成本**？
- 哪一步**主要决定风险**？
- 哪一步**主要决定用户体验或信任**？

> 不同商业模式共存时，最多画两条链，并说明为什么两条都必要。

## 🆚 多公司对比表

| 公司 | 价值创造核心 | 主要赚钱方式 | 主要利润引擎 | 最大成本/风险 | 核心经营矛盾 |
|------|-------------|-------------|-------------|--------------|-------------|

**「核心经营矛盾」要暴露模型里的张力**，例如：

- 服务体验带来定价权，但吃掉毛利
- 硬件带来用户，软件带来利润
- 高毛利技术服务很赚钱，但客户高度集中
- 靠爆款吃饭，没有第二利润引擎

## 🔗 项目对接（可选）

用户提供项目或要求把项目接进企业价值链时才做：

> 该项目位于 **[经营链环节]**，主要改变 **[收入/成本/风险/体验]**，机制是 **[方式]**。它在公司层面的重要性取决于 **[所需的联动或规模]**。

> ❌ 没有证据时，不把一个项目夸大成公司级利润驱动。

---

## 🧾 证据标准

优先级：**经审计年报/财报** → **官方 IR 材料与监管文件** → **权威行业或监管来源**

对重要的公司特定主张，给出**来源链接 + 报告期**。证据不足时：

1. 能拿到一手资料就去拿；
2. 拿不到就**明说哪些无法核实**，并让结论保持条件性，而不是标成「已披露」。

**三类陈述严格区分**：
- **披露** —— 来源直接陈述
- **计算** —— 由披露数字推导，必要时给出公式或推理
- **推断** —— 业务解释，明确标注

> ❌ 公司只披露收入或把多条业务合并在一个分部时，**绝不**给某条业务线编造利润或毛利率 —— 应说明「未单独披露」。

---

## 📄 输出要求

**单公司**：
1. **Layer 1 表格**：付款方 / 付款原因 / 收入机制 / 核心收入 / 核心利润 / 主要成本 / 关键风险 / 一句话本质
2. **Layer 2 经营链** —— 一条箭头链
3. **决策点表**：收入 / 成本 / 风险 / 体验
4. **核心经营矛盾**的简短综合

**多公司**：先给 Layer 1 合并对比表，再每家一个紧凑的 Layer 2，最后给跨公司差异。

---

## ✅ 交付前自检

- ☐ 收入来源与利润来源没有混淆
- ☐ 毛利、营业利润、净利润、现金流已区分
- ☐ 战略重要性没有被当成盈利能力
- ☐ 链条从真实客户需求开始，到回款或留存结束
- ☐ 只保留真正决定价值的少数步骤
- ☐ 无证据支撑的内部流程标记为「推断」
- ☐ 最终一句话足以把这家公司和竞争对手区分开
